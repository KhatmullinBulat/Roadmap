# Переменная

## Кратко

Переменная — именованная ячейка памяти (или имя, с которым связано значение), через которую программа хранит и изменяет данные. В императивных языках переменная связана с типом, областью видимости и временем жизни, а в функциональных часто заменяется неизменяемыми связями.

## Главное

Переменная в императивном программировании — именованная либо адресуемая иным способом абстрактная/виртуальная или физическая память. Адрес, на который указывается переменная, используется для доступа к данным, а данные, находящиеся в переменной, называются **значением** этой переменной. Свойства значений в переменной явно или неявно определяются типом переменной.

В других парадигмах программирования, например в функциональной и логической, понятие переменной оказывается несколько иным. В таких языках переменная определяется как **имя**, с которым может быть *связано значение*, или даже как **место** (location) для хранения значения.

Область видимости и/или время существования переменной в языках программирования задаются классом памяти.

### Из чего «состоит» переменная

| Понятие | Что означает |
| --- | --- |
| Имя (идентификатор) | как программа ссылается на значение |
| Значение | данные, которые хранятся |
| Тип | какие операции допустимы со значением |
| Адрес / место | где значение физически или виртуально хранится |
| Область видимости | где имя доступно в коде |
| Время жизни | когда память выделена и освобождена |
| Изменяемость | можно ли связать имя с новым значением |

### Классы памяти

- **Статическая (static)** — выделяется при запуске программы; например, глобальные переменные.
- **Стековая (automatic)** — выделяется при входе в функцию и освобождается при выходе; локальные переменные.
- **Динамическая (heap)** — время жизни не привязано к функции; память освобождается сборщиком мусора или вручную.

### Ссылки и значения

В языках с ссылочной моделью (JavaScript, Python, Java для объектов) переменная хранит не сам объект, а ссылку на него. Отсюда возникают алиасинг и неожиданное «общее» изменение данных. В C переменная-указатель может хранить адрес другого места памяти.

```js
let a = { n: 1 }
let b = a // b ссылается на тот же объект
b.n = 2
a.n // 2
```
