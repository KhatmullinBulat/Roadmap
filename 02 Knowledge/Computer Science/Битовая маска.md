# Битовая маска

## Кратко

Битовая маска — число, отдельные биты которого используются как независимые флаги. Маску объединяют с данными через `&`, `|` и `^`, чтобы проверить, установить или снять сразу несколько признаков одной операцией.

## Главное

Битовая маска — целое число, в котором каждый бит отвечает за отдельное свойство. Например, права доступа к файлу можно хранить в одном числе:

| Бит | Значение | Право |
| --- | --- | --- |
| 1 (0b001) | 1 | чтение |
| 2 (0b010) | 2 | запись |
| 4 (0b100) | 4 | выполнение |

Комбинация прав — это сумма степеней двойки: чтение и запись — `1 | 2 = 3` (`0b011`).

### Основные операции

- **Проверить флаг**: `(flags & READ) !== 0` — `&` оставляет только общие биты, результат ненулевой, если флаг установлен.
- **Установить флаг**: `flags |= WRITE`.
- **Снять флаг**: `flags &= ~WRITE` — `~WRITE` инвертирует биты, и `&` обнуляет нужный.
- **Переключить флаг**: `flags ^= EXECUTE`.
- **Проверить, что установлены все флаги**: `(flags & needed) === needed`.
- **Проверить, что установлен хотя бы один**: `(flags & needed) !== 0`.

```js
const READ = 1 << 0 // 0b001
const WRITE = 1 << 1 // 0b010
const EXEC = 1 << 2 // 0b100

let flags = READ | EXEC
flags & WRITE // 0 — записи нет
flags & READ // 1 — чтение есть

flags |= WRITE // 0b111
flags &= ~EXEC // 0b011
flags ^= READ // 0b010 — только запись

(flags & (READ | WRITE)) === (READ | WRITE) // false — не все
(flags & (READ | WRITE)) !== 0 // true — хотя бы одно
```

### Перечисление флагов

В TypeScript удобно оформлять флаги через `enum`:

```ts
enum Permission {
  Read = 1 << 0,
  Write = 1 << 1,
  Execute = 1 << 2,
}

const p = Permission.Read | Permission.Write
```

### Ограничения в JavaScript

Операции `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>` работают с 32-битными целыми. Число больше `2**31 - 1` или дробное будет усечено по модулю `2**32`, поэтому маска подходит только для 32 флагов и целых значений.

```js
2 ** 31 | 0 // -2147483648 — знаковое усечение
```

Для большего количества флагов используют `Set`, `BigInt` или массив булевых значений.

### Где применяют

- права доступа (Unix-права, ACL);
- флаги конфигурации и опций;
- сжатое хранение множеств в алгоритмах (динамическое программирование по подмножествам, решето Эратосфена с битовым вектором);
- графические и звуковые алгоритмы (маски каналов);
- сетевые маски и IP-адреса.
