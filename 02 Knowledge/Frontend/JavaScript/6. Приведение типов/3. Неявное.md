# 3. Неявное

## Кратко

Неявное приведение — это преобразование, которое выполняет сам язык, когда операция ожидает другой тип: `1 + "1"` даёт строку, `"5" * 2` — число, `if (value)` — булев результат. Знать правила полезно, чтобы понимать поведение `==`, `+` и условий, а в новом коде лучше предпочитать явные преобразования и `===`.

## Главное

### Где именно происходит

| Контекст | Цель | Пример |
| --- | --- | --- |
| арифметика (`-`, `*`, `/`, `%`) | число | `"5" * 2 // 10` |
| `+` | строка, если есть строка | `1 + "1" // "11"` |
| сравнение `<`, `>`, `<=`, `>=` | число | `"10" < "9" // true` |
| `==` | зависит от операндов | `"" == 0 // true` |
| условие `if`, `&&`, `\|\|`, `!` | логическое | `if ("") {}` |
| шаблонная строка | строка | `` `${[]}` // "" ` |
| ключ свойства | строка или символ | `obj[1]` === `obj["1"]` |

### `+` особенный

```js
1 + 2 + "3" // "33" — слева направо: (1+2) → "3"
"3" + 1 + 2 // "312"
1 + "2" * 3 // 7 — сначала умножение, затем сложение
```

Не забывайте о приоритете: унарный `+` и `*` выполняются раньше, чем `+` с конкатенацией, а скобки делают намерение явным.

### Сравнения: `==` и `<`

```js
"10" < "9" // true — обе строки, идёт лексикографическое сравнение
10 < "9" // false — строка "9" приводится к числу
"10" < 9 // false

null == 0 // false — особое правило
undefined == null // true
"" == 0 // true
"0" == false // true
NaN == NaN // false
```

`==` по-разному обрабатывает пары: `null`/`undefined` сравниваются только друг с другом, объект с примитивом — через `ToPrimitive`, булево значение всегда приводит операнд к числу. Запоминать все комбинации не нужно: `===` избавляет от большинства проблем.

```js
0 === "" // false
0 === false // false
null === undefined // false
```

Для проверки «значение отсутствует» часто пишут `value == null`, но такой код явно выделяйте комментарием. В остальных случаях — `===`.

### Условия и неявный `Boolean`

```js
if ("0") console.log("сработает") // непустая строка истинна
if ([]) console.log("сработает") // массив всегда истинен
if (0) console.log("не сработает")
```

Логические операторы возвращают не `boolean`, а операнд:

```js
const name = input || "гость" // "" и 0 заменяются на "гость"
const count = value ?? 0 // только null/undefined
```

`||` и `??` различаются именно неявным приведением: `||` проверяет «ложность», `??` — только отсутствие значения.

### Методы и `indexOf`/`includes`

```js
[1, 2, 3].indexOf("2") // -1 — строгий поиск, "2" не равно 2
[1, 2, 3].includes("2") // false

"123".indexOf(2) // 1 — строка приводит число к строке
```

В методах массива сравнение обычно строгое (`SameValueZero`), а методы строк приводят аргумент к строке. Это частая причина «невидимых» ошибок при поиске значений из форм.
