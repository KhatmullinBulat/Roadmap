# Прототипное наследование

## Кратко

Прототипное наследование — механизм, по которому объект получает свойства и методы от своего прототипа: поиск идёт вверх по цепочке до `null`. Крайне важно различать `[[Prototype]]` объекта и свойство `prototype` функции — вторая связь используется при вызове с `new` и в классах.

## Главное

В JavaScript свойства могут наследоваться через цепочку прототипов. Если свойства нет у объекта, движок поднимается к его прототипу; поиск останавливается, когда свойство найдено или достигнут `null`.
```js
const vehicle = {
  move() {
    return `${this.name} движется`
  },
}

const bike = Object.create(vehicle)
bike.name = "Велосипед"

bike.move() // "Велосипед движется"
```

В примере метод хранится в `vehicle`, но при вызове `bike.move()` значение `this` равно `bike`. Поэтому метод читает собственное свойство `bike.name`.

Если у объекта и прототипа есть свойство с одинаковым ключом, собственное свойство **затеняет** унаследованное.
```js
const defaults = { theme: "light" }
const settings = Object.create(defaults)

settings.theme // "light"
settings.theme = "dark"
settings.theme // "dark"
defaults.theme // "light"
```

### `[[Prototype]]` и `prototype`

Это разные понятия:
- `[[Prototype]]` — внутренняя ссылка конкретного объекта на его прототип. Её читают через `Object.getPrototypeOf()`.
- `Function.prototype` — обычное свойство функции. При вызове функции с `new` оно становится прототипом созданного экземпляра.

```js
function User(name) {
  this.name = name
}

User.prototype.greet = function () {
  return `Привет, ${this.name}`
}

const user = new User("Bulat")
Object.getPrototypeOf(user) === User.prototype // true
```

Синтаксис `class` строится на той же модели: методы класса размещаются в объекте прототипа и разделяются экземплярами. Классы не отменяют прототипное наследование, а дают более удобную запись поверх него.

Не путайте наследование свойств с копированием: объект-потомок хранит ссылку на прототип. Изменение свойства в прототипе может быть видно всем потомкам, если оно не затенено собственным свойством.

### Как этим пользоваться в классах

```js
class Animal {
  constructor(name) {
    this.name = name
  }
  speak() {
    return `${this.name} издаёт звук`
  }
}

class Dog extends Animal {
  speak() {
    return `${super.speak()} — гав`
  }
}

const rex = new Dog("Rex")
Object.getPrototypeOf(rex) === Dog.prototype // true
Object.getPrototypeOf(Dog.prototype) === Animal.prototype // true
```

`extends` выстраивает цепочку прототипов: экземпляр → `Dog.prototype` → `Animal.prototype` → `Object.prototype` → `null`. Ключевое `super` обращается к методу прототипа родителя.

### Зачем это нужно знать

- Методы, общие для всех экземпляров, хранятся в prototype и не дублируются в каждом объекте.
- `instanceof` и `isPrototypeOf` работают по этой цепочке.
- Смешение классов и ручного `Object.create` в одном коде быстро становится неподдерживаемым — выбирайте один стиль.
