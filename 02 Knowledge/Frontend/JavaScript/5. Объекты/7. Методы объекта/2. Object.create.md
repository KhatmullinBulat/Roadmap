# 2. Object.create

## Кратко

Создаёт новый объект с указанным прототипом и, опционально, с описанными свойствами.

**Мутирует объект:** новый объект
**Возвращает:** новый объект с указанным прототипом

## Синтаксис

```js
Object.create(proto)
Object.create(proto, propertiesObject)
```

## Главное

```js
const animal = {
  eats: true,
}

const rabbit = Object.create(animal)
rabbit.jumps = true

console.log(rabbit.eats) // true — из прототипа
console.log(rabbit.jumps) // true — собственное

const dict = Object.create(null)
console.log(Object.getPrototypeOf(dict)) // null
```

- Первый аргумент — прототип: объект или `null`.
- Второй аргумент — объект с дескрипторами свойств, а не со значениями.
- `Object.create(null)` даёт «чистый» объект без `toString` и `hasOwnProperty` — удобно как словарь.

## Ограничения и типичные ошибки

- Второй аргумент — дескрипторы: `{ x: { value: 1, enumerable: true } }`, а не `{ x: 1 }`.
- `Object.create()` не копирует свойства прототипа в собственные.
- Не путайте с `Object.assign({}, obj)` — тот копирует свойства, но не прототип.

## Практика

- [ ] Создать объект с прототипом и проверить `Object.getPrototypeOf`
- [ ] Сделать словарь через `Object.create(null)` и проверить отсутствие `hasOwnProperty`
- [ ] Задать свойство через дескриптор во втором аргументе
