# 14. Object.hasOwn

## Кратко

Проверяет, есть ли у объекта собственное свойство с указанным ключом.

**Мутирует объект:** не мутирует
**Возвращает:** `true` или `false`

## Синтаксис

```js
Object.hasOwn(obj, prop)
```

## Главное

```js
const user = Object.create({ inherited: 1 })
user.own = 2

console.log(Object.hasOwn(user, "own")) // true
console.log(Object.hasOwn(user, "inherited")) // false
console.log("inherited" in user) // true — in смотрит и в прототип
```

- Замена `obj.hasOwnProperty(key)`, которая не ломается на объектах с `null`-прототипом.
- Не вызывает методы из прототипа — безопасно для недоверенных данных.
- Появился в ES2022.

## Ограничения и типичные ошибки

- `in` проверяет и унаследованные свойства — не путайте.
- У `Object.create(null)` нет `hasOwnProperty`, но `Object.hasOwn` работает.

## Практика

- [ ] Сравнить `Object.hasOwn`, `in` и `hasOwnProperty`
- [ ] Проверить объект с `null`-прототипом
- [ ] Показать, что свойство со значением `undefined` считается собственным
