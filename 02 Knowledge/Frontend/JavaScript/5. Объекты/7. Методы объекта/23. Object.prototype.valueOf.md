# 23. Object.prototype.valueOf

## Кратко

Возвращает примитивное значение объекта; базовый вариант возвращает сам объект.

**Мутирует объект:** не мутирует
**Возвращает:** примитивное значение (обычно сам объект)

## Синтаксис

```js
obj.valueOf()
```

## Главное

```js
const obj = {}
console.log(obj.valueOf() === obj) // true

const price = {
  amount: 100,
  valueOf() {
    return this.amount
  },
}

console.log(price + 50) // 150
```

- Участвует в `ToPrimitive` при подсказке `"number"` или `"default"`.
- Базовая реализация просто возвращает объект.
- Переопределение меняет поведение `+`, `<`, `==` и других операций.

## Ограничения и типичные ошибки

- Не переопределяйте без причины — это неявно влияет на сравнения.
- `valueOf` не вызывается при `String(obj)` — там сработает `toString`.

## Практика

- [ ] Переопределить `valueOf` и посмотреть на `obj + 1`
- [ ] Проверить, что базовый `valueOf` возвращает объект
- [ ] Сравнить с `Symbol.toPrimitive`
