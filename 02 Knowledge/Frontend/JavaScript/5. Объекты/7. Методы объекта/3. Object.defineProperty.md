# 3. Object.defineProperty

## Кратко

Определяет одно новое свойство или изменяет существующее с явными флагами дескриптора.

**Мутирует объект:** тот же объект
**Возвращает:** тот же объект (`Object`)

## Синтаксис

```js
Object.defineProperty(obj, prop, descriptor)
```

## Главное

```js
const user = {}

Object.defineProperty(user, "id", {
  value: 42,
  writable: false,
  enumerable: false,
  configurable: false,
})

user.id = 100 // молча игнорируется в нестрогом режиме
console.log(user.id) // 42
console.log(Object.keys(user)) // [] — не перечисляемое
```

- Дескриптор данных: `value`, `writable`, `enumerable`, `configurable`.
- Дескриптор аксессора: `get`, `set`, `enumerable`, `configurable`.
- Флаги по умолчанию `false` — в отличие от литерала объекта, где всё `true`.
- В строгом режиме запись в не-writable свойство бросает `TypeError`.

## Ограничения и типичные ошибки

- Забытые `enumerable: true` делают свойство невидимым для `Object.keys` и `for...in`.
- Нельзя смешивать `value`/`writable` с `get`/`set` в одном дескрипторе.
- `configurable: false` означает, что свойство нельзя удалить и его флаги нельзя изменить.

## Практика

- [ ] Сделать свойство только для чтения и проверить присваивание в строгом режиме
- [ ] Сделать неперечисляемое свойство и сравнить `Object.keys` и `Object.getOwnPropertyNames`
- [ ] Создать геттер через дескриптор
