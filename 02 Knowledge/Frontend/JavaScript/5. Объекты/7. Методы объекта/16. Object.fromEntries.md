# 16. Object.fromEntries

## Кратко

Создаёт объект из итерируемого набора пар `[ключ, значение]`.

**Мутирует объект:** не мутирует
**Возвращает:** новый объект

## Синтаксис

```js
Object.fromEntries(iterable)
```

## Главное

```js
const entries = [["name", "Bulat"], ["city", "Уфа"]]

console.log(Object.fromEntries(entries)) // { name: "Bulat", city: "Уфа" }

const withLength = Object.fromEntries(
  Object.entries({ a: 1, bb: 2 }).map(([k, v]) => [k, v * 2]),
)
console.log(withLength) // { a: 2, bb: 4 }
```

- Принимает `Map` и любой итерируемый объект пар.
- Обратен `Object.entries()`.
- Ключи приводятся к строкам или символам, как всегда в объектах.

## Ограничения и типичные ошибки

- Если в парах дублируется ключ, останется последнее значение.
- `Object.fromEntries` создаёт обычный объект: ключ `__proto__` становится обычным свойством, прототип не меняется.

## Практика

- [ ] Сделать объект из `Map`
- [ ] Отфильтровать объект через `entries` → `map`/`filter` → `fromEntries`
- [ ] Проверить дублирующиеся ключи
