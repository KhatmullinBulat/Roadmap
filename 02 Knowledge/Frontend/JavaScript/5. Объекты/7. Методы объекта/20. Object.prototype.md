# 20. Object.prototype

## Кратко

Прототип, от которого наследуются обычные объекты; завершает цепочку прототипов.

**Мутирует объект:** не мутирует
**Возвращает:** объект-прототип

## Синтаксис

```js
Object.prototype
```

## Главное

```js
const user = { name: "Bulat" }

console.log(Object.getPrototypeOf(user) === Object.prototype) // true
console.log(Object.getPrototypeOf(Object.prototype)) // null
console.log(Object.prototype.toString.call([])) // "[object Array]"
```

- Содержит методы `toString`, `valueOf`, `hasOwnProperty`, `isPrototypeOf` и другие.
- Не расширяйте его — это влияет на все объекты.
- `Object.prototype.toString.call(x)` даёт тег внутреннего типа.

## Ограничения и типичные ошибки

- `null`-прототип (`Object.create(null)`) не наследует методы `Object.prototype`.
- Модификация влияет на все объекты в окружении и на `for...in`.
