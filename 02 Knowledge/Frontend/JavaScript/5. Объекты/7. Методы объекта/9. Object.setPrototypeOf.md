# 9. Object.setPrototypeOf

## Кратко

Заменяет прототип уже созданного объекта.

**Мутирует объект:** тот же объект (мутирует прототип)
**Возвращает:** переданный объект

## Синтаксис

```js
Object.setPrototypeOf(obj, proto)
```

## Главное

```js
const animal = { eats: true }
const dog = { barks: true }

Object.setPrototypeOf(dog, animal)
console.log(dog.eats) // true
console.log(Object.getPrototypeOf(dog) === animal) // true
```

- Редко нужен: прототип лучше задавать при создании через `Object.create()` или `__proto__` в литерале.
- Работает и со вторым аргументом `null`.
- Влияет на всю цепочку поиска свойств объекта.

## Ограничения и типичные ошибки

- Медленный: замена прототипа деоптимизирует объекты в движке.
- Может сломать `instanceof` и код, полагающийся на прототип.
- `Object.setPrototypeOf()` лучше, чем `obj.__proto__ = ...`.
