# 6. Object.freeze

## Кратко

Замораживает объект: свойства нельзя добавлять, изменять и удалять.

**Мутирует объект:** сам объект (изменён: заморожен)
**Возвращает:** переданный объект

## Синтаксис

```js
Object.freeze(obj)
```

## Главное

```js
const config = Object.freeze({ theme: "dark", retries: 3 })

config.theme = "light" // игнорируется
config.extra = true // игнорируется
console.log(config) // { theme: "dark", retries: 3 }

console.log(Object.isFrozen(config)) // true
```

- Заморозка поверхностная: вложенные объекты остаются изменяемыми.
- В строгом режиме попытка изменения бросает `TypeError`.
- `Object.freeze()` возвращает тот же объект, а не копию.

## Ограничения и типичные ошибки

- Главная ошибка — считать `Object.freeze()` глубокой заморозкой.
- Замороженный массив можно изменить только через пересоздание.
- Не замораживайте объект, если рядом есть код, который мутирует его свойства.

## Практика

- [ ] Проверить `Object.isFrozen` до и после
