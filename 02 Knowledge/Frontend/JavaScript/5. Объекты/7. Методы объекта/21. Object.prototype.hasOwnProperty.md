# 21. Object.prototype.hasOwnProperty

## Кратко

Устаревающий метод: проверяет, есть ли у объекта собственное свойство.

**Мутирует объект:** не мутирует
**Возвращает:** `true` или `false`

## Синтаксис

```js
obj.hasOwnProperty(prop)
Object.prototype.hasOwnProperty.call(obj, prop)
```

## Главное

```js
const user = { name: "Bulat" }

console.log(user.hasOwnProperty("name")) // true
console.log(user.hasOwnProperty("toString")) // false — не собственное

const dict = Object.create(null)
// dict.hasOwnProperty("x") // TypeError
```

- Статический `Object.hasOwn()` — современная замена.
- Работает только если метод не переопределён в объекте.
- У `null`-прототипа метод отсутствует.

## Ограничения и типичные ошибки

- Может быть переопределён: `{ hasOwnProperty: 1 }` сломает вызов.
- Не работает у `Object.create(null)` — используйте `Object.hasOwn`.

## Практика

- [ ] Сравнить `hasOwnProperty` и `Object.hasOwn`
- [ ] Создать объект с `hasOwnProperty: null` и показать поломку
- [ ] Проверить на `null`-прототипе
