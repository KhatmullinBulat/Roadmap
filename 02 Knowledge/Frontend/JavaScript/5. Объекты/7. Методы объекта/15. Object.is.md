# 15. Object.is

## Кратко

Сравнивает два значения по `SameValue`: строже `===` (корректно различает `NaN` и `0`/`-0`).

**Мутирует объект:** не мутирует
**Возвращает:** `true` или `false`

## Синтаксис

```js
Object.is(value1, value2)
```

## Главное

```js
console.log(Object.is(NaN, NaN)) // true
console.log(NaN === NaN) // false

console.log(Object.is(0, -0)) // false
console.log(0 === -0) // true

console.log(Object.is("a", "a")) // true
```

- `Object.is` — это алгоритм `SameValue` из спецификации.
- `===` использует `SameValueZero` с точки зрения поведения `NaN` и `-0`.
- Пригодится в тестах для строгого сравнения значений.

## Ограничения и типичные ошибки

- `Object.is` не заменяет `===` во всём коде: он был создан для редких случаев.
- При сравнении объектов сравниваются ссылки, а не содержимое.
