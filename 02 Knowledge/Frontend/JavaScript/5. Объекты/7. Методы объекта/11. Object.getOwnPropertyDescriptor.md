# 11. Object.getOwnPropertyDescriptor

## Кратко

Возвращает дескриптор указанного собственного свойства.

**Мутирует объект:** не мутирует
**Возвращает:** объект-дескриптор или `undefined`

## Синтаксис

```js
Object.getOwnPropertyDescriptor(obj, prop)
```

## Главное

```js
const user = { name: "Bulat" }

console.log(Object.getOwnPropertyDescriptor(user, "name"))
// { value: "Bulat", writable: true, enumerable: true, configurable: true }

console.log(Object.getOwnPropertyDescriptor(user, "missing")) // undefined
```

- Возвращает либо дескриптор данных (`value`, `writable`), либо дескриптор аксессора (`get`, `set`).
- Плюс флаги `enumerable` и `configurable`.
- Для унаследованных свойств вернёт `undefined`.

## Ограничения и типичные ошибки

- Унаследованное свойство нужно читать через `Object.getOwnPropertyDescriptor(Object.getPrototypeOf(obj), key)`.
- Не используйте для чтения значения — для этого есть обычный доступ.
