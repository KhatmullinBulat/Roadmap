# 24. Object.prototype.isPrototypeOf

## Кратко

Проверяет, входит ли объект в цепочку прототипов другого объекта.

**Мутирует объект:** не мутирует
**Возвращает:** `true` или `false`

## Синтаксис

```js
proto.isPrototypeOf(obj)
```

## Главное

```js
const animal = { eats: true }
const rabbit = Object.create(animal)

console.log(animal.isPrototypeOf(rabbit)) // true
console.log(Object.prototype.isPrototypeOf({})) // true
console.log(animal.isPrototypeOf(animal)) // false
```

- Похож на `instanceof`, но сравнивает объекты-прототипы, а не конструкторы.
- Сам объект не считается своим прототипом.
- Работает по всей цепочке, а не только на первом уровне.

## Ограничения и типичные ошибки

- `isPrototypeOf` проверяет цепочку, `Object.hasOwn` — собственные свойства.
- Для `null`-прототипа цепочка обрывается сразу.
