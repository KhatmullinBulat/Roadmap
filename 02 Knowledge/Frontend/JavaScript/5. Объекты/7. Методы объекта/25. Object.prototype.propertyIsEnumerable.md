# 25. Object.prototype.propertyIsEnumerable

## Кратко

Проверяет, является ли свойство собственным и перечисляемым.

**Мутирует объект:** не мутирует
**Возвращает:** `true` или `false`

## Синтаксис

```js
obj.propertyIsEnumerable(prop)
```

## Главное

```js
const obj = { visible: 1 }
Object.defineProperty(obj, "hidden", { value: 2 })

console.log(obj.propertyIsEnumerable("visible")) // true
console.log(obj.propertyIsEnumerable("hidden")) // false
console.log(obj.propertyIsEnumerable("toString")) // false — не собственное
```

- Собственный и перечисляемый — оба условия сразу.
- Унаследованные перечисляемые свойства дают `false`.
- Полезен при обходе в `for...in`.

## Ограничения и типичные ошибки

- Такое свойство может быть переопределено в объекте — вызывайте через `Object.prototype.propertyIsEnumerable.call`.
- Для `null`-прототипа метод недоступен.
