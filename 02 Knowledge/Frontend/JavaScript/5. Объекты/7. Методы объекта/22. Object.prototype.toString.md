# 22. Object.prototype.toString

## Кратко

Возвращает строку с внутренним тегом типа объекта.

**Мутирует объект:** не мутирует
**Возвращает:** строку `[object Тип]`

## Синтаксис

```js
obj.toString()
Object.prototype.toString.call(value)
```

## Главное

```js
console.log({}.toString()) // "[object Object]"
console.log([].toString()) // ""

console.log(Object.prototype.toString.call([])) // "[object Array]"
console.log(Object.prototype.toString.call(null)) // "[object Null]"
console.log(Object.prototype.toString.call(new Date())) // "[object Date]"
```

- Через `Object.prototype.toString.call(x)` определяется внутренний тип.
- Свойство `Symbol.toStringTag` меняет тег у кастомных классов.
- `[].toString()` вызывает `Array.prototype.toString`, а не этот метод.

## Ограничения и типичные ошибки

- Массив переопределяет `toString` — поэтому нужен `.call` от `Object.prototype`.
- `null` и `undefined` нельзя вызывать напрямую — только через `call`.

## Практика

- [ ] Получить теги для массива, даты, `null` и функции
- [ ] Определить тип через `toString.call`, а не `typeof`
- [ ] Задать `Symbol.toStringTag` в классе
