# 19. Object.constructor

## Кратко

Ссылка на функцию-конструктор, создавшую объект (из прототипа).

**Мутирует объект:** не мутирует
**Возвращает:** функцию-конструктор

## Синтаксис

```js
obj.constructor
```

## Главное

```js
const user = {}
const date = new Date()

console.log(user.constructor === Object) // true
console.log(date.constructor === Date) // true
console.log([].constructor === Array) // true
```

- `constructor` берётся из прототипа, а не является собственным свойством.
- У `Object.create(null)` его нет.
- Может быть переопределён — не используйте для надёжной проверки типа.

## Ограничения и типичные ошибки

- `obj.constructor` — ненадёжная проверка: его можно переопределить.
- Для проверки типа используйте `Array.isArray`, `instanceof` или `Object.prototype.toString.call`.

## Практика

- [ ] Проверить `constructor` у литерала, массива и даты
- [ ] Переопределить `constructor` и показать, что проверка ломается
- [ ] Сравнить с `instanceof`
