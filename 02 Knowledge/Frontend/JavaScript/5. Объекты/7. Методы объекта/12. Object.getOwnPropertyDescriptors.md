# 12. Object.getOwnPropertyDescriptors

## Кратко

Возвращает карту дескрипторов всех собственных свойств объекта.

**Мутирует объект:** не мутирует
**Возвращает:** объект из дескрипторов

## Синтаксис

```js
Object.getOwnPropertyDescriptors(obj)
```

## Главное

```js
const source = { a: 1 }
Object.defineProperty(source, "b", { value: 2, enumerable: false })

const copy = Object.create(
  Object.getPrototypeOf(source),
  Object.getOwnPropertyDescriptors(source),
)

console.log(copy.b) // 2 — неперечисляемое сохранилось
```

- В отличие от spread и `Object.assign`, сохраняет флаги и геттеры.
- Возвращает объект, где ключ — имя свойства, значение — дескриптор.
- Идеален для точного клонирования объекта.

## Ограничения и типичные ошибки

- Дороже `Object.assign` и реже нужен.
- Символьные ключи тоже включаются.

## Практика

- [ ] Склонировать объект с сохранением дескрипторов
- [ ] Убедиться, что геттер не превратился в значение
- [ ] Сравнить с `{ ...obj }`
