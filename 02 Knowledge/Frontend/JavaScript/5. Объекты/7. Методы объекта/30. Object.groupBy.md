# 30. Object.groupBy

## Кратко

Группирует элементы итерируемого объекта по строковому ключу из функции.

**Мутирует объект:** не мутирует
**Возвращает:** новый объект с группами

## Синтаксис

```js
Object.groupBy(iterable, callbackFn)
```

## Главное

```js
const inventory = [
  { name: "виноград", type: "фрукты" },
  { name: "морковь", type: "овощи" },
  { name: "яблоко", type: "фрукты" },
]

const grouped = Object.groupBy(inventory, (item) => item.type)

console.log(grouped.fruits) // [{ виноград }, { яблоко }]
console.log(grouped["овощи"]) // [{ морковь }]
```

- Появился в ES2024 (ранее был `Array.prototype.group`).
- Возвращает обычный объект: ключи строковые, с прототипом `null`.
- Для нестроковых ключей используют `Map.groupBy()`.

## Ограничения и типичные ошибки

- Нет в старых браузерах и Node — нужен полифилл или `reduce`.
- Ключ `"__proto__"` безопасен, так как результат идёт с `null`-прототипом.
- Группы хранятся в массивах и сохраняют исходный порядок.

## Практика

- [ ] Сгруппировать товары по категории
- [ ] Показать, что для `null`-прототипа `grouped.hasOwnProperty` не работает
- [ ] Заменить `groupBy` на `reduce`-реализацию
