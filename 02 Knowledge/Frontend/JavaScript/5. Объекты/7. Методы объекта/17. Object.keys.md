# 17. Object.keys

## Кратко

Возвращает массив собственных перечисляемых строковых ключей.

**Мутирует объект:** не мутирует
**Возвращает:** массив строковых ключей

## Синтаксис

```js
Object.keys(obj)
```

## Главное

```js
const user = { name: "Bulat", city: "Уфа" }

console.log(Object.keys(user)) // ["name", "city"]
console.log(Object.keys({})) // []
console.log(Object.keys("ab")) // ["0", "1"]
```

- Порядок: целочисленные ключи по возрастанию, затем в порядке добавления.
- Символьные и неперечисляемые ключи не включаются.
- Для массивов вернёт индексы, а не `length`.

## Ограничения и типичные ошибки

- Ключ `"0"` в массиве — это строковый ключ, а не число.
- Не работает как `for...in` — не включает унаследованные свойства.
