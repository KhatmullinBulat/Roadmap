# 29. Object.isSealed

## Кратко

Проверяет, что объект запечатан: добавить и удалить свойства нельзя.

**Мутирует объект:** не мутирует
**Возвращает:** `true` или `false`

## Синтаксис

```js
Object.isSealed(obj)
```

## Главное

```js
const sealed = Object.seal({ a: 1 })
const frozen = Object.freeze({ a: 1 })

console.log(Object.isSealed(sealed)) // true
console.log(Object.isSealed(frozen)) // true — замороженный тоже запечатан
console.log(Object.isSealed({})) // false
```

- Замороженный объект всегда запечатан, обратное неверно.
- Для пустого объекта после `preventExtensions` вернёт `true`.
- Не учитывает вложенные объекты.

## Ограничения и типичные ошибки

- `isSealed` не означает «неизменяемый»: значения существующих свойств можно менять.
- Как и `seal`, проверка поверхностная.
