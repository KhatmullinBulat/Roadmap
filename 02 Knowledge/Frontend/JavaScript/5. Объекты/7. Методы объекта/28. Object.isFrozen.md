# 28. Object.isFrozen

## Кратко

Проверяет, что объект заморожен полностью.

**Мутирует объект:** не мутирует
**Возвращает:** `true` или `false`

## Синтаксис

```js
Object.isFrozen(obj)
```

## Главное

```js
const frozen = Object.freeze({ a: 1 })
const sealed = Object.seal({ a: 1 })

console.log(Object.isFrozen(frozen)) // true
console.log(Object.isFrozen(sealed)) // false
console.log(Object.isFrozen({})) // false
```

- Пустой объект после `preventExtensions` формально считается замороженным: менять нечего.
- Проверка поэлементная: все свойства должны быть неперезаписываемыми и непереопределяемыми.
- Не учитывает вложенные объекты.

## Ограничения и типичные ошибки

- `isFrozen` поверхностная, как и `freeze`.
- Объект с геттерами без сеттеров может считаться замороженным при `preventExtensions`.
