# 27. Object.isExtensible

## Кратко

Проверяет, можно ли добавлять новые свойства в объект.

**Мутирует объект:** не мутирует
**Возвращает:** `true` или `false`

## Синтаксис

```js
Object.isExtensible(obj)
```

## Главное

```js
const a = {}
const b = Object.preventExtensions({})

console.log(Object.isExtensible(a)) // true
console.log(Object.isExtensible(b)) // false
console.log(Object.isExtensible(Object.freeze({}))) // false
```

- Вернёт `false` и для замороженных, и для запечатанных объектов.
- Соответствует `[[IsExtensible]]` из спецификации.
- Полезно в библиотеках, когда нужно проверить режим защиты.

## Ограничения и типичные ошибки

- `isExtensible` не говорит, можно ли менять значения — для этого `isFrozen`/`isSealed`.
- Для `null`-прототипа работает обычным образом.
