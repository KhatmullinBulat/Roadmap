# 13. Object.getOwnPropertySymbols

## Кратко

Возвращает массив собственных символьных ключей объекта.

**Мутирует объект:** не мутирует
**Возвращает:** массив символов

## Синтаксис

```js
Object.getOwnPropertySymbols(obj)
```

## Главное

```js
const id = Symbol("id")
const user = { [id]: 42, name: "Bulat" }

console.log(Object.getOwnPropertySymbols(user)) // [Symbol(id)]
console.log(user[Object.getOwnPropertySymbols(user)[0]]) // 42
```

- Символьные ключи не попали в `Object.keys()` и `for...in`.
- Возвращает только собственные символы, без унаследованных.
- `Reflect.ownKeys()` объединяет строковые и символьные ключи.

## Ограничения и типичные ошибки

- Символы не сереализуются в JSON — это важно при отправке данных.
- Получив список символов, значения читайте через `obj[sym]`.
