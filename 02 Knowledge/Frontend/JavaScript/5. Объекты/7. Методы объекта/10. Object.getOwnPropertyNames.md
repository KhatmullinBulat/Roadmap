# 10. Object.getOwnPropertyNames

## Кратко

Возвращает все собственные строковые ключи, включая неперечисляемые.

**Мутирует объект:** не мутирует
**Возвращает:** массив строковых ключей

## Синтаксис

```js
Object.getOwnPropertyNames(obj)
```

## Главное

```js
const obj = {}
Object.defineProperty(obj, "hidden", { value: 1 })
obj.visible = 2

console.log(Object.keys(obj)) // ["visible"]
console.log(Object.getOwnPropertyNames(obj)) // ["hidden", "visible"]
```

- В отличие от `Object.keys()`, включает неперечисляемые свойства.
- Символьные ключи не возвращает — для них `getOwnPropertySymbols`.
- У массива вернёт `length` и другие служебные ключи.

## Ограничения и типичные ошибки

- Чаще всего нужно для отладки и метапрограммирования, а не для прикладного кода.
- Порядок гарантирован так же, как у `Object.keys()`.
