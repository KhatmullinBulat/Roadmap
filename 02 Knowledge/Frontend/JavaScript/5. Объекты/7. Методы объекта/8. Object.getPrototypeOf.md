# 8. Object.getPrototypeOf

## Кратко

Возвращает прототип (`[[Prototype]]`) указанного объекта.

**Мутирует объект:** не мутирует
**Возвращает:** прототип объекта или `null`

## Синтаксис

```js
Object.getPrototypeOf(obj)
```

## Главное

```js
const animal = { eats: true }
const rabbit = Object.create(animal)

console.log(Object.getPrototypeOf(rabbit) === animal) // true
console.log(Object.getPrototypeOf({})) // Object.prototype
console.log(Object.getPrototypeOf(Object.prototype)) // null
```

- Единственный надёжный способ прочитать прототип.
- Для объекта, созданного через `Object.create(null)`, вернёт `null`.
- `__proto__` — устаревший аксессор с теми же данными, но с подвохами.

## Ограничения и типичные ошибки

- На примитивах метод сначала упаковывает значение, а в ES2015 бросает `TypeError` на `null`/`undefined`.
- Не путайте с `obj.prototype` — у обычного объекта такого свойства нет.
