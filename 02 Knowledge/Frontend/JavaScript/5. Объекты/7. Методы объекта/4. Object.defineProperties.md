# 4. Object.defineProperties

## Кратко

Определяет сразу несколько свойств по карте дескрипторов.

**Мутирует объект:** тот же объект
**Возвращает:** тот же объект

## Синтаксис

```js
Object.defineProperties(obj, props)
```

## Главное

```js
const point = {}

Object.defineProperties(point, {
  x: { value: 3, enumerable: true },
  y: { value: 4, enumerable: true },
})

console.log(point) // { x: 3, y: 4 }
```

- Эквивалент нескольких вызовов `Object.defineProperty()`.
- Атомарная замена: если один дескриптор некорректен, изменения могут быть частично применены.
- Пустой второй аргумент допустим — объект не меняется.

## Ограничения и типичные ошибки

- Все правила `defineProperty` действуют и здесь.
- Порядок перечисления свойств в объекте-карте сохраняется для однотипных ключей.
