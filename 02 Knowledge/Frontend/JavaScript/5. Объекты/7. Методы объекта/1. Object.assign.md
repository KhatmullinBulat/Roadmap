# 1. Object.assign

## Кратко

Копирует перечисляемые собственные свойства из источников в целевой объект и возвращает его.

**Мутирует объект:** целевой объект (мутируется)
**Возвращает:** тот же объект `target`

## Синтаксис

```js
Object.assign(target, ...sources)
```

## Главное

```js
const defaults = { theme: "light", size: 14 }
const config = Object.assign({}, defaults, { size: 16 })

console.log(config) // { theme: "light", size: 16 }
console.log(defaults) // { theme: "light", size: 14 } — не изменён
```

- Копирование поверхностное: вложенные объекты и массивы передаются по ссылке.
- Если передать `{}` первым аргументом — получится копия без мутации источника.
- Свойства с ключом `__proto__` в источнике могут поменять прототип цели.
- Символьные ключи тоже копируются — в отличие от `Object.keys()`.

## Ограничения и типичные ошибки

- `Object.assign(target, ...)` всегда мутирует `target`.
- `undefined` и `null` в источниках игнорируются, а в цели — `TypeError`.
- Геттеры вызываются и копируется уже значение, а не сам дескриптор.

## Практика

- [ ] Сделать копию объекта через `Object.assign({}, obj)` и сравнить с `{ ...obj }`
- [ ] Скопировать объект с `__proto__` и проверить, не изменился ли прототип
- [ ] Показать, что вложенный объект скопирован по ссылке
