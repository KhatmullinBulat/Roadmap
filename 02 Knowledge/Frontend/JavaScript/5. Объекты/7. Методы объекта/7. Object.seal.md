# 7. Object.seal

## Кратко

Запрещает добавлять и удалять свойства, но позволяет менять значения существующих.

**Мутирует объект:** сам объект (изменён: запечатан)
**Возвращает:** переданный объект

## Синтаксис

```js
Object.seal(obj)
```

## Главное

```js
const user = Object.seal({ name: "Bulat" })

user.name = "Анна" // можно
user.age = 22 // игнорируется
console.log(user) // { name: "Анна" }

console.log(Object.isSealed(user)) // true
```

- Все существующие свойства становятся `configurable: false`.
- В отличие от `freeze`, значения менять можно.
- Возвращает тот же объект.

## Ограничения и типичные ошибки

- Не защищает от изменения вложенных объектов.
- Удаление свойства в строгом режиме бросит `TypeError`, в нестрогом — молча не сработает.

## Практика

- [ ] Сравнить `seal` и `freeze` на одном объекте
- [ ] Показать, что новое свойство не добавляется
- [ ] Проверить `Object.isSealed` и `Object.isFrozen`
