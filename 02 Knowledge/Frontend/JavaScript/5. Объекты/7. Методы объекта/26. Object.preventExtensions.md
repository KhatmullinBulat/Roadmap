# 26. Object.preventExtensions

## Кратко

Запрещает добавлять новые свойства, не трогая существующие.

**Мутирует объект:** сам объект (изменён)
**Возвращает:** переданный объект

## Синтаксис

```js
Object.preventExtensions(obj)
```

## Главное

```js
const user = Object.preventExtensions({ name: "Bulat" })

user.name = "Анна" // можно
user.age = 22 // игнорируется
console.log(user) // { name: "Анна" }
console.log(Object.isExtensible(user)) // false
```

- Самый мягкий режим защиты: менять и удалять свойства можно.
- `seal` и `freeze`在此基础上 ужесточают правила.
- Возвращает тот же объект.

## Ограничения и типичные ошибки

- Не защищает вложенные объекты.
- В строгом режиме попытка добавить свойство бросит `TypeError`.
