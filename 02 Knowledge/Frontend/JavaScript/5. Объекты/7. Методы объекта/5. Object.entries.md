# 5. Object.entries

## Кратко

Возвращает массив собственных перечисляемых строковых пар ключ-значение.

**Мутирует объект:** новый массив
**Возвращает:** массив пар `[ключ, значение]`

## Синтаксис

```js
Object.entries(obj)
```

## Главное

```js
const user = { name: "Bulat", city: "Уфа" }

for (const [key, value] of Object.entries(user)) {
  console.log(key, value)
}

console.log(Object.entries(user)) // [["name", "Bulat"], ["city", "Уфа"]]
```

- Символьные ключи не попадают в результат.
- Порядок: целочисленные ключи по возрастанию, затем в порядке добавления.
- Часто используется вместе с `Object.fromEntries()` для трансформации объекта.

## Ограничения и типичные ошибки

- `entries` не работает как `for...in` — не включает унаследованные свойства.
- Для символов — `Object.getOwnPropertySymbols()` или `Reflect.ownKeys()`.

## Практика

- [ ] Преобразовать объект в массив и обратно через `entries`/`fromEntries`
- [ ] Отфильтровать пары и собрать объект заново
