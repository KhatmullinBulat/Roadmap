# 18. Object.values

## Кратко

Возвращает массив значений собственных перечисляемых свойств.

**Мутирует объект:** не мутирует
**Возвращает:** массив значений

## Синтаксис

```js
Object.values(obj)
```

## Главное

```js
const prices = { apple: 100, banana: 80 }

console.log(Object.values(prices)) // [100, 80]
console.log(Object.values(prices).reduce((a, b) => a + b, 0)) // 180
```

- Порядок соответствует `Object.keys()`.
- Удобен для агрегаций: суммы, максимумы, фильтры.
- Для массива вернёт сами элементы.

## Ограничения и типичные ошибки

- Символьные свойства не попадают в результат.
- У строк возвращает символы.
