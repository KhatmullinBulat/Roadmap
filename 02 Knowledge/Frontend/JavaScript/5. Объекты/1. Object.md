# Object

## Кратко

Объект — значение типа `object` из набора пар «ключ → значение», где ключом служит строка или символ. Объекты создают литералом `{}`, доступ к свойствам идёт через точку или скобки, а `const` защищает только переменную, но не содержимое объекта.

## Главное

Объект — значение типа `object`, которое хранит набор свойств. Свойство состоит из ключа и значения; значением может быть любой тип, включая функцию. Функцию в свойстве обычно называют методом.
```js
const user = {
  name: "Bulat",
  age: 22,
  greet() {
    return `Привет, ${this.name}`
  },
}
```

### Создание и изменение

Объект обычно создают литералом `{}`. Вызов `new Object()` даёт тот же результат, но используется редко.
```js
const settings = {}
settings.theme = "dark"
settings["font size"] = 16

delete settings.theme
```

`const` запрещает переназначить переменную, но не замораживает сам объект:
```js
const user = { name: "Bulat" }
user.name = "Анна" // допустимо
// user = {} // TypeError
```

### Ключи и доступ к свойствам

Ключом свойства может быть строка или [[8. Symbol|символ]]. Числа и другие значения при использовании как ключа приводятся к строке.
```js
const scores = { 1: "one" }
scores[1] // "one"
scores["1"] // "one"
```

Точечная запись подходит для известных имён, которые являются допустимыми идентификаторами. Скобочная запись нужна для динамического ключа, ключа с пробелом или символа.
```js
const key = "display name"
user[key]
user.name
```

В литерале можно использовать вычисляемый ключ и сокращённую запись свойства:
```js
const field = "email"
const email = "bulat@example.com"

const profile = {
  [field]: email,
  email,
}
```

### Собственные и унаследованные свойства

Оператор `in` ищет свойство и в объекте, и в его цепочке прототипов. Для проверки только собственных свойств используйте `Object.hasOwn()`.
```js
Object.hasOwn(user, "name") // true
"toString" in user // true: свойство унаследовано от Object.prototype
```

Для перебора собственных перечисляемых строковых ключей подходят `Object.keys()`, `Object.values()` и `Object.entries()`. Не используйте `obj.hasOwnProperty()` для внешних данных: метод может быть переопределён или отсутствовать у объекта с `null`-прототипом.

### Деструктуризация, spread и копирование

```js
const user = { name: "Bulat", role: "student" }

const { name, role = "guest" } = user

const updated = { ...user, role: "admin" }

const { role: _ , ...rest } = user
rest // { name: "Bulat" }
```

Spread и `Object.assign()` делают **неглубокую** копию: вложенные объекты остаются общими.

```js
const a = { nested: { x: 1 } }
const b = { ...a }
b.nested.x = 2
a.nested.x // 2 — копия поверхностная

const deep = structuredClone(a) // глубокая копия
```

### Порядок ключей

Строковые ключи перечисляются в порядке: целые индексы по возрастанию, затем ключи в порядке добавления; символы идут отдельно. Не полагайтесь на порядок как на бизнес-правило, кроме случаев, когда порядок гарантирован спецификацией.

### Проверка пустоты

```js
Object.keys({}).length === 0
Object.entries(user).length === 0
```

Для проверки «есть ли собственные свойства» используют `Object.keys().length` или `Reflect.ownKeys()`, если важны и символы.
