Имя переменной — это идентификатор. Оно может содержать буквы Unicode, цифры, `$` и `_`, но не может начинаться с цифры. Регистр важен: `userName` и `username` — разные имена.
```js
const userName = "Bulat"
const $element = document.body
const _cache = new Map()

// const 2faEnabled = true // SyntaxError
```

В прикладном JavaScript обычно используют английские слова и `camelCase`:
```js
const totalPrice = 1_500
let isLoading = false
function getUserById(id) {}
```

Полезные соглашения:
- давайте переменным название по смыслу, а не по типу: `users`, а не `usersArray`;
- используйте `is`, `has`, `can` для булевых значений: `isOpen`, `hasAccess`;
- не сокращайте имя, если сокращение не общеизвестно в контексте (`index`, `event`, `id` обычно понятны);
- не используйте зарезервированные слова языка: `class`, `return`, `await` и другие;
- начальный `_` — только соглашение команды. Язык не делает такое свойство приватным.

Допустимые с точки зрения языка имена не всегда удачны для кода. Главное правило — имя должно объяснять назначение значения без дополнительного комментария.
