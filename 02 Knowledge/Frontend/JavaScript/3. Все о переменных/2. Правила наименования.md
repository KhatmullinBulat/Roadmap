Мы можем назвать переменную практически как угодно, но есть ограничения. Как правило, следует использовать только латинские символы (0-9, az, AZ) и символ подчеркивания.

- Не следует использовать другие символы, поскольку это может привести к ошибкам или быть сложным для понимания международной аудиторией
- Не использовать нижние подчеркивания в начале имен переменных - в некоторых конструкциях JavaScript это используется для обозначения определенных вещей, поэтому может вызвать путаницу
- Не использовать цифры в начале переменных. Это недопустимо и приводит к ошибке
- Надежный способ написания слов - использование строчных букв в верблюжьем регистре (lower camel case), когда несколько слов объединяются, при этом первое слово пишется строчными буквами, а последующие - с заглавной буквы
- Названия переменных должны быть интуитивно понятными, чтобы они описывали содержащиеся в них данные. Не использовать только отдельные буквы/цифры или длинные фразы
- Регистр символов в переменных имеет значение - поэтому `myage` это другая переменная, нежели `myAge`
- Также необходимо избегать использования зарезервированных слов JavaScript в качестве имен переменных
