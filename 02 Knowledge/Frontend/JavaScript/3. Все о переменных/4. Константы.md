# Константы

## Кратко

`const` объявляет переменную с блочной областью видимости, которую нельзя переназначить, и требует сразу указать значение. Содержимое объекта или массива при этом остаётся изменяемым — `const` защищает только привязку имени к значению.

## Главное

`const` объявляет переменную с блочной областью видимости, которую нельзя переназначить. При объявлении ей обязательно нужно сразу дать значение.
```js
const birthday = "2004-05-05"
// birthday = "2001-01-01" // TypeError
```

Важно: `const` не делает значение неизменяемым. Она защищает только саму связь между именем и значением. Если константа хранит объект или массив, их содержимое по-прежнему можно менять.
```js
const user = { name: "Bulat" }
user.name = "Анна" // допустимо

const tags = ["js"]
tags.push("web") // допустимо
```

В новом коде удобно начинать с `const` и переходить на `let` только там, где переменную действительно нужно переназначить. Это уменьшает число случайных изменений состояния.

### Имена констант

`UPPER_SNAKE_CASE` обычно используют для значений, которые известны заранее и выглядят как неизменяемые настройки или общеизвестные константы:
```js
const MAX_RETRIES = 3
const API_BASE_URL = "https://api.example.com"
```

Если значение вычислено во время выполнения, но затем не переназначается, имя обычно остаётся в `camelCase`:
```js
const pageLoadTime = performance.now()
```

### Как получить настоящую неизменяемость

```js
const config = Object.freeze({ theme: "dark", retries: 3 })
config.theme = "light" // молча игнорируется
config.theme // "dark"
```

`Object.freeze()` запрещает изменение свойств, но только на первом уровне: вложенные объекты остаются изменяемыми. Для глубокой заморозки нужен отдельный рекурсивный обход или библиотека. В строгом режиме попытка записи в замороженный объект приводит к `TypeError`, а не к молчаливому игнорированию.

```js
"use strict"
const config = Object.freeze({ a: 1 })
// config.a = 2 // TypeError
```

Важно: `Object.freeze()` действует на данные, а не на код, и не работает как «глубокая» заморозка. Для структур, которые изменяются, лучше не полагаться на `const` как на защиту от мутаций.
