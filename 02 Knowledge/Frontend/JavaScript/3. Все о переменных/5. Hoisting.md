# 5. Hoisting

## Кратко

Hoisting — это не перенос строк, а создание привязок имён до выполнения кода. У `var` и объявлений функций имя доступно сразу (`var` со значением `undefined`, функция целиком), а у `let`, `const` и `class` в этот период возникает временная мёртвая зона (TDZ).

## Главное

**Hoisting** («поднятие») — разговорное название поведения, при котором объявления становятся известны движку до построчного выполнения кода. Важно не представлять это как буквальное перемещение строк: движок заранее создаёт привязки имён в области видимости.

У `var` объявление доступно с начала функции или глобального скрипта и сразу имеет значение `undefined`; присваивание не «поднимается».
```js
console.log(city) // undefined
var city = "Екатеринбург"

// Упрощённая модель:
// var city
// console.log(city)
// city = "Екатеринбург"
```

`let`, `const` и `class` тоже создают привязку до выполнения строки, но до инициализации находятся во **временной мёртвой зоне** (*temporal dead zone*, TDZ). Обращение к ним в этот период вызывает `ReferenceError`.
```js
console.log(count) // ReferenceError
let count = 0
```

Объявления функций доступны вместе с телом функции, поэтому функцию можно вызвать раньше её определения:
```js
greet()

function greet() {
  console.log("Привет")
}
```

Лучше не полагаться на hoisting для порядка кода: объявляйте значения до их использования. Тогда различия `var`, `let` и `const` не становятся скрытой причиной ошибки.

### Объявления функций и функциональные выражения

Функциональные выражения, а также функции, объявленные через `const`/`let`, не поднимаются вместе с телом:
```js
hoisted() // работает

function hoisted() {
  console.log("function declaration")
}

// notHoisted() // TypeError: notHoisted is not a function
const notHoisted = function () {
  console.log("function expression")
}
```

Причина в том, что у `const` в TDZ лежит ещё не инициализированная привязка, а не ссылка на функцию. Это частая ошибка, потому что `function` и `const f = () => {}` на вид похожи.

### Что поднимается и что нет

| Конструкция | Результат до стоки объявления |
| --- | --- |
| `var x` | `undefined` |
| `function f() {}` | готовая функция |
| `let x`, `const x`, `class X` | `ReferenceError` (TDZ) |
| `const f = () => {}` | `ReferenceError` (TDZ) |

## Практика

- [ ] Написать три фрагмента: с `var`, с `let` и с функцией — и предсказать вывод до запуска
- [ ] Объяснить, почему `typeof x` в TDZ бросает ошибку, а для необъявленного имени — нет
- [ ] Найти в легаси-коде вызов функции до её объявления и проверить, не сломается ли он при переходе на `const`
