# Объявления переменных

## Кратко

Переменная — именованное хранилище значения. В JavaScript её объявляют через `let` (значение будет меняться), `const` (не будет переназначаться) или устаревший `var`. По умолчанию выбирают `const`, а на `let` переходят только при необходимости.

## Главное

[[Переменная]] связывает имя со значением. Объявление создаёт это имя в определённой области видимости, а инициализация назначает ему первое значение. В JavaScript переменные объявляют с помощью `let`, `const` или `var`.
```js
let userName // объявление; значение — undefined
userName = "Bulat" // присваивание

let age = 22 // объявление и инициализация
const language = "JavaScript"
```

`let` используют, когда значение позже нужно переназначить. `const` используют по умолчанию, если сама переменная не будет получать другое значение. `var` — устаревший способ объявления, который встречается в старом коде и имеет другую область видимости.
```js
let count = 0
count += 1

const user = { name: "Bulat" }
user.name = "Анна" // допустимо: меняется объект, а не связь user
// user = {} // TypeError: константу нельзя переназначить
```

Лучше объявлять одну переменную в строке и располагать объявление рядом с первым использованием. Так код проще читать, а область действия имени — отслеживать.

### Сравнение `let`, `const` и `var`

| Свойство | `let` | `const` | `var` |
| --- | --- | --- | --- |
| Область видимости | блок | блок | функция |
| Повторное объявление | ошибка | ошибка | разрешено |
| Доступ до объявления | `ReferenceError` (TDZ) | `ReferenceError` (TDZ) | `undefined` (hoisting) |
| Требует значения при объявлении | нет | да | нет |
| Свойство глобального объекта | нет | нет | да (в скрипте) |

```js
let a = 1
const b = 2
var c = 3

{ let a = 10 } // отдельная переменная в блоке
// b = 20 // TypeError
```

### Частые ошибки

- Объявлять `const` без значения: `const x;` — синтаксическая ошибка.
- Думать, что `const` «замораживает» объект: свойства можно менять, если объект не пропущен через `Object.freeze()`.
- Создавать неявные глобальные переменные без `"use strict"`: присваивание необъявленному имени в строгом режиме даёт `ReferenceError`.
- Повторно объявлять через `let` в той же области — это `SyntaxError`, а не переопределение.
