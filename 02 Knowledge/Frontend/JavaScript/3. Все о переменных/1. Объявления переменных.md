Объявление переменной вводит имя переменной в текущую область видимости. JavaScript предоставляет три способа объявления переменных: **var**, **let**, **const**. Выбор между ними влияет на область видимости, поведение при всплытии переменной и возможность переназначения переменной.

[[Переменная]] - это "именованное хранилище" для данных. Мы можем использовать переменные для хранения товаров, посетителей и других данных. Это контейнер для значения, например число, которое мы можем использовать как часть предложения.

Без переменной мы не можем узнать, сколько раз была нажата кнопка. Сообщение для пользователя быстро станет неактуальным, если никакая информация не будет запомнена.

Одна из особенностей переменных заключается в том, что они могут содержать практически все, что угодно - не только строки и числа. Переменные также могут содержать сложные данные и даже целые функции, способные выполнять удивительные вещи.

Чтобы использовать переменную, сначала нужно ее создать - точнее, объявить переменную. Для этого нужно ввести ключевое слово `let`, а затем имя, которое вы хотите присвоить своей переменной:
```js
let myName;
let myAge;
```
Здесь мы создаем две переменные с именами `myName` и `myAge`.

В данный момент они не имеют значения; это пустые контейнеры. При вводе имен переменных вы должны получить возвращаемое значение `undefined`. Если они не существуют, мы получим сообщение об ошибке.

После объявления переменной ее можно инициализировать значением. Для этого нужно указать имя переменной, затем знак равенства (`=`), а затем значение, которое мы хотим ей присвоить. Например:
```js
myName = "Bulat";
myAge = 22;
```
Можно объявить и инициализировать переменную одновременно, например, так:
```js
let myDog = "Rover"
```
После инициализации переменной значением, мы можем изменить (или обновить) это значение, присвоив ему другое значение.

Также можно объявить несколько переменных в одной строке:
```js
let user = "John", age = 25, message = "Hello"
```
Такой способ может показаться короче, но он не рекомендуется. Для лучшей читаемости лучше объявлять каждую переменную на новой строке.

Многострочный вариант немного длиннее, но легче для чтения:
```js
let user = "John"
let age = 25
let message = "Hello"
```
Некоторые люди также определяют несколько переменных в таком вот многострочном стиле:
```js
let user = "John",
	age = 25,
	message = "Hello"
```

Также можно объявить две переменные и скопировать данные из одной в другую.
```js
let hello = "Hello world!"

let message

// копируем значение "Hello world!" из переменной hello в переменную message
message = hello

// теперь две переменные содержат одинаковые данные
console.log(hello) // Hello world!
console.log(message) // Hello world!
```
