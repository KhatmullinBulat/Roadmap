Также есть другой способ объявления переменных с использованием ключевого слова `var`:
```js
var myName;
var myAge;
```
Когда JavaScript только появился, это был единственный способ объявлять переменные. Конструкция `var` была запутанной и чреватой ошибками. Поэтому в современных версиях JavaScript было создано новое ключевое слово `let` для создания переменных, которое работает несколько иначе, чем `var`, исправляя при этом его недостатки. 

Если написать многострочную программу на JavaScript, которая объявляет и инициализирует переменную, мы можем объявить переменную с помощью `var` после инициализации, и она все равно будет работать. Например:
```js
myName = "Bulat"

function logName() {
	console.log(myName)
}

logName()

var myName
```
Это работает благодаря **механизму подъема переменных** [[5. Hoisting|Hoisting]].

Поднятие переменных больше не работает с `let`. Если бы мы изменили `var` на `let` в приведенном выше примере, это привело бы к ошибке. Это хорошо - объявление переменной после ее инициализации приводит к запутанному и труднопонимаемому коду.

Во-вторых, при использовании `var` мы можем объявлять одну и ту же переменную сколько угодно раз, а с `let` это невозможно. Следующий код будет работать:
```js
var myName = "Bulat"
var myName = "Chris"
```
Но следующий код вызовет ошибку на второй строке:
```js
let myName = "Bulat"
let myName = "Chris"
```
В глобальной области видимости `var` - переменная становится свойством объекта [[window]], подробнее об этом можно прочитать в спецификации [[3. ECMAScript|ECMAScript]]. Для `let` и `const` этого не происходит, они остаются глобальными, но не добавляются в `window`. 

Если при создании var-переменной в глобальном объекте `window` уже есть неудаляемое свойство с тем же именем, новое значение тому свойству назначено не будет.
```js
console.log(window.document) // HTMLDocument

var document = "Мой документ"

console.log(window.document) // HTMLDocument
console.log(document) // "Мой документ"
```
