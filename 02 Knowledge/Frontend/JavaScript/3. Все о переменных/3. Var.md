`var` — старый способ объявить переменную. В новом коде почти всегда стоит выбирать `const` или `let`.

Главные отличия `var`:
- область видимости — функция или глобальный код, а не ближайший блок;
- переменную можно повторно объявить в той же области видимости;
- объявление инициализируется значением `undefined` до выполнения строки объявления;
- глобальный `var` в классическом браузерном скрипте создаёт свойство `window`.

```js
if (true) {
  var status = "ready"
}

console.log(status) // "ready": var не ограничен блоком if
```

```js
console.log(name) // undefined
var name = "Bulat"

var name = "Анна" // повторное объявление допустимо
```

Такое поведение легко приводит к ошибкам, особенно в циклах и вложенных блоках. `let` и `const` имеют блочную область видимости, не допускают повторного объявления в одной области и находятся во временной мёртвой зоне до инициализации. Подробнее — в заметках [[5. Hoisting|Hoisting]] и [[6. Область видимости|Область видимости]].

`var` остаётся важным для чтения легаси-кода и понимания старых библиотек, но не как стиль для нового проекта.
