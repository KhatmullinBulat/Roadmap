# 3. ECMAScript

## Кратко

ECMAScript — стандарт языка, описанный в спецификации ECMA-262 и развиваемый комитетом TC39. JavaScript — его самая распространённая реализация; спецификация описывает язык, но не браузерные API вроде DOM или `fetch`.

## Главное

**ECMAScript** — стандарт языка программирования, описанный спецификацией ECMA-262. Он определяет синтаксис JavaScript, его типы, объекты, операторы и встроенные API, но не описывает браузерные возможности вроде DOM или `fetch`.

JavaScript — самая известная реализация ECMAScript. Другие реализации и диалекты могут добавлять собственные API, но совместимый код ориентируется на требования стандарта.

Стандарт впервые приняли в 1997 году. Ранние редакции ES1, ES2, ES3 и ES5 выходили нерегулярно. После ES5.1 комитет TC39 перешёл на ежегодные выпуски: ES2015, ES2016 и далее. Поэтому «ES6» и «ES2015» — одно и то же название одной редакции.

Новые возможности сначала проходят несколько стадий обсуждения в TC39. В стандарт попадают только предложения, достигшие четвёртой стадии (*Stage 4*). Это помогает браузерам и инструментам заранее готовить реализацию, но использовать предложение в продакшене стоит с учётом его поддержки.

### Стадии предложений TC39

| Стадия | Что означает |
| --- | --- |
| 0 | Идея, ещё не оформлена |
| 1 | Принятое предложение, есть ответственный и описание |
| 2 | Утверждённая форма API, начинается прототипирование |
| 2.7 | Позиция урегулирована, предварительная спецификация и реализация |
| 3 | Спецификация готова, нужна обратная связь от реализаций |
| 4 | Готово к включению в стандарт, будет в следующей редакции |

### Что стандарт оставляет браузеру

Спецификация ECMAScript описывает ядро языка: типы, объекты, операторы, `Promise`, `Map`, генераторы. А вот `document`, `fetch`, `localStorage`, `setTimeout`, `console` определяют другие спецификации — HTML Living Standard, Fetch, Web Storage и т.д. Поэтому движок может полностью соответствовать ECMA-262, но в нём не будет DOM — так выглядит Node.js.
