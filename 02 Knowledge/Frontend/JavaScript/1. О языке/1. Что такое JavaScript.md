# 1. Что такое JavaScript

## Кратко

JavaScript — высокоуровневый, динамически типизированный язык программирования, который выполняется в браузере, на сервере (Node.js, Deno, Bun) и во встроенных средах. Сам язык задаёт синтаксис, типы и встроенные объекты, а всё остальное — DOM, файлы, сеть — добавляет окружение.

## Главное

JavaScript — высокоуровневый язык программирования для создания интерактивных приложений. Изначально он появился в браузере, а сегодня выполняется и на сервере, в инструментах сборки, настольных и мобильных приложениях.

Программа на JavaScript называется *скриптом*. В браузере скрипт можно подключить к HTML-документу; среда выполнения загрузит и выполнит его. Современные движки обычно не просто «интерпретируют» код, а разбирают его и при необходимости компилируют в машинный код.

Сам язык определяет синтаксис, типы, объекты и стандартные встроенные возможности. Доступ к файлам, сети, DOM и другим API предоставляет не JavaScript как таковой, а окружение: браузер, Node.js или другое runtime-окружение.

В браузере JavaScript может:
- изменять содержимое и стили страницы через DOM;
- реагировать на действия пользователя;
- выполнять сетевые запросы и работать с ответами сервера;
- хранить данные в cookie, `localStorage`, IndexedDB и других браузерных хранилищах;
- обращаться к камере, микрофону, буферу обмена и другим устройствам — если браузер и пользователь это разрешили.

### Ограничения браузера

Код страницы выполняется в изолированной среде. Он не получает произвольный доступ к файлам, приложениям и устройствам пользователя. Например, сайт может работать с выбранным пользователем файлом, но не может незаметно прочитать весь диск.

Данные между сайтами также изолированы политикой одинакового источника (*same-origin policy*). Источник определяется схемой, доменом и портом. Поэтому страница с одного источника не может прочитать DOM или данные страницы с другого источника. Обмен данными между источниками возможен только через явно предусмотренные механизмы, например CORS или `postMessage`.

### Где ещё работает JavaScript

Современный JavaScript не ограничен браузером:
- **Node.js** — серверный рантайм на движке V8, добавляющий файловую систему, сеть, процессы и npm-экосистему;
- **Deno и Bun** — более новые рантаймы; Deno делает упор на безопасность и Web API, Bun — на скорость;
- **Electron, Tauri** — настольные приложения на веб-технологиях;
- **React Native, Capacitor** — мобильные приложения;
- **встроенные движки** в играх, базах данных и инструментах вроде Excalidraw.

### Строгий режим и модули

В ES-модулях и классах автоматически включён *строгий режим* (`"use strict"`). Он запрещает неявные глобальные переменные, присваивание необъявленным именам и ряд небезопасных конструкций. В обычном скрипте его включают директивой в начале файла или функции.
