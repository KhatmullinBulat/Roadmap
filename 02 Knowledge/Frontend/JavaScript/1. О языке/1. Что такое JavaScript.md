JavaScript - это высокоуровневый интерпретируемый язык программирования, созданный для добавления интерактивности веб-страницам. Он работает в браузере, а с Node.js - и на сервере. JavaScript - единственный язык, который работает непосредственно в веб-браузерах, что делает его основой фронтенд-разработки.

Программы на этом языке называются *скриптами*. Они могут встраиваться в **HTML** и выполняться автоматически при загрузке веб-страницы.

Скрипты распространяются и выполняются, как простой текст. Им не нужна специальная подготовка или компиляция для запуска.
