# 4. Какие есть версии и чем они отличаются

## Кратко

Версии JavaScript — это редакции стандарта ECMAScript. Главный рубеж — ES2015 (ES6) с `let`/`const`, классами, модулями и промисами; после него язык обновляется ежегодными небольшими выпусками.

## Главное

Версии JavaScript обычно называют версиями стандарта [[3. ECMAScript|ECMAScript]]. На практике полезно помнить не номер каждой редакции, а два периода развития языка.

- **ES3 и ES5/ES5.1** заложили основу современного JavaScript: строгий режим, JSON, методы массивов, геттеры и сеттеры.
- **ES2015 (ES6)** стал крупным обновлением: появились `let` и `const`, классы, модули, промисы, стрелочные функции, деструктуризация, `Map`, `Set`, `Symbol` и многое другое.
- **ES2016 и новее** выходят ежегодно и добавляют отдельные возможности: `async`/`await`, `BigInt`, optional chaining, private fields, top-level `await` и другие.

Указание «ES6» в вакансиях и статьях обычно означает современный JavaScript, хотя формально ES6 — только стандарт 2015 года. При выборе синтаксиса важнее проверить поддержку целевых браузеров и сред выполнения, чем ориентироваться на номер стандарта. Если поддержка нужна, инструменты вроде Babel могут преобразовать часть нового синтаксиса в более совместимый код.

### Что добавилось в заметных редакциях

| Редакция | Заметные нововведения |
| --- | --- |
| ES5 (2009) | строгий режим, `JSON`, `Array.prototype.forEach/map/filter/reduce`, геттеры и сеттеры, `Object.keys` |
| ES2015 (ES6) | `let`/`const`, классы, модули, промисы, стрелочные функции, `Map`/`Set`, `Symbol`, генераторы |
| ES2016 | `Array.prototype.includes`, оператор возведения в степень `**` |
| ES2017 | `async`/`await`, методы `Object.values`/`entries`, `padStart`/`padEnd` |
| ES2018–2019 | rest/spread для объектов, асинхронные итераторы, `flat`/`flatMap`, `Object.fromEntries`, `try` без `catch` |
| ES2020 | `?.`, `??`, `BigInt`, `Promise.allSettled`, `globalThis`, `import()` |
| ES2021–2022 | `replaceAll`, `Promise.any`, приватные поля классов, `at()`, `Object.hasOwn`, top-level `await` |
| ES2023+ | `findLast`, `toSorted`/`toReversed`/`with`, поддержка хешбэнгов |

### Как выбрать уровень синтаксиса

1. Определите целевые браузеры и среды — по статистике проекта или `browserslist`.
2. Сверьте поддержку через MDN Browser Compatibility или caniuse.
3. Если нужную возможность не поддерживает заметная доля аудитории, подключите транспиляцию (Babel, TypeScript) и polyfill (`core-js`).
4. Не ориентируйтесь на номер версии из вакансии: «ES6» часто означает «современный JS», а не конкретную редакцию 2015 года.
