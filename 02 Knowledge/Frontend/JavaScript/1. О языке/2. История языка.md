JavaScript был первоначально создан Бренданом Эйхом из NetScape и впервые анонсирован в пресс-релизе NetScape в 1995 году. История его именования довольно странная: первоначально создатель назвал его **Mocha**, позже переименовав в **LiveScript**. В 1996 году, примерно через год после релиза, NetScape решила переименовать его в **JavaScript**, надеясь извлечь выгоду из сообщества **Java** (хотя JavaScript не имел никакого отношения к Java), и выпустила NetScape 2.0 с официальной поддержкой JavaScript.

Со временем JavaScript стал полностью независимым языком со своей собственной спецификацией, называющейся [[ECMAScript]].
