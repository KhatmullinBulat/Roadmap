# 2. История языка

## Кратко

JavaScript появился в 1995 году в Netscape за десять дней как Mocha/LiveScript, в 1997 году был стандартизирован как ECMAScript, а после «войны браузеров» и ES5.1 стал развиваться ежегодными редакциями силами комитета TC39.

## Главное

JavaScript создал Брендан Эйх в Netscape в 1995 году. Первая версия языка появилась в браузере Netscape Navigator 2.0. На разработку ушло около десяти дней, поэтому ранний язык унаследовал ряд необычных решений, которые заметны до сих пор.

У языка было несколько названий: сначала **Mocha**, затем **LiveScript** и, наконец, **JavaScript**. Последнее имя выбрали в период популярности Java; оно было маркетинговым решением. Несмотря на созвучие, JavaScript и Java — разные языки с разными моделями выполнения и историей развития.

Чтобы разные браузеры могли реализовывать язык одинаково, Netscape передала его на стандартизацию в Ecma International. В 1997 году вышла первая редакция стандарта ECMA-262. Стандартизированный язык получил название [[3. ECMAScript|ECMAScript]], а JavaScript остался наиболее распространённой реализацией этого стандарта.

До JavaScript веб-страницы в основном были статическими HTML-документами. Язык позволил менять страницу без полной перезагрузки, реагировать на действия пользователя и обмениваться данными с сервером. Со временем JavaScript вышел за пределы браузера благодаря серверным и встроенным средам выполнения.

### Ключевые этапы

| Год | Событие |
| --- | --- |
| 1995 | Netscape: Mocha → LiveScript → JavaScript |
| 1996 | JScript в Internet Explorer 3; «война браузеров» и расхождения реализаций |
| 1997 | ECMA-262 (ES1) — первый стандарт |
| 1999 | ES3: регулярные выражения, `try...catch`, `do...while` |
| 2005 | Ajax и `XMLHttpRequest` делают JS основой интерактивных веб-приложений |
| 2009 | ES5: строгий режим, `JSON`, методы массивов |
| 2009 | Начало работы над ES4 (отменена) и создание Node.js Райаном Далем |
| 2015 | ES2015 (ES6): `let`/`const`, классы, модули, промисы, стрелочные функции |
| 2015+ | Ежегодные редакции; TC39 принимает предложения только на Stage 4 |

Провал ES4 показателен: слишком радикальные изменения синтаксиса без согласия всех вендоров не попали в стандарт. После этого TC39 перешёл к инкрементальным, ежегодным выпускам, где каждая возможность сначала проходится по стадиям предложения.
