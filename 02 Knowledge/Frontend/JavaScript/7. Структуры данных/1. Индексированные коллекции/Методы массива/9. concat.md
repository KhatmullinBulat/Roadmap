# 9. concat

## Кратко

Объединяет исходный массив с переданными массивами и значениями в новый массив.

**Мутирует исходный массив:** нет
**Возвращает:** новый массив

## Синтаксис

```js
concat()
concat(value1, …, valueN)
```

## Главное

```js
const a = [1, 2]
const b = [3, 4]

console.log(a.concat(b)) // [1, 2, 3, 4]
console.log(a.concat(5, b, 6)) // [1, 2, 5, 3, 4, 6]
console.log(a) // [1, 2] — исходный не изменён
```

- Массивы раскрываются на один уровень.
- Эквивалент `[...a, ...b]` для массивов.
- `Symbol.isConcatSpreadable` управляет раскрытием объекта.

## Ограничения и типичные ошибки

- Не работает рекурсивно — для вложенности нужен `flat(Infinity)`.
- Массивоподобный объект без `Symbol.isConcatSpreadable` станет одним элементом.
