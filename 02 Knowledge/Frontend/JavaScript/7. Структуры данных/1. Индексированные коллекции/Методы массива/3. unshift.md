# 3. unshift

## Кратко

Добавляет один или несколько элементов в начало массива и возвращает новую длину.

**Мутирует исходный массив:** да
**Возвращает:** новую длину массива (`number`)

## Синтаксис

```js
unshift(element1, …, elementN)
```

## Главное

```js
const fruits = ["Апельсин", "Груша"]
const count = fruits.unshift("Яблоко")

console.log(fruits) // ["Яблоко", "Апельсин", "Груша"]
console.log(count) // 3
```

- Элементы встают в переданном порядке: `arr.unshift(1, 2)` даст `[1, 2, ...]`.

## Ограничения и типичные ошибки

- `O(n)`: сдвигает все индексы, на больших массивах заметно медленнее `push`.
- Мутирует массив; для копии — `[item, ...arr]`.
