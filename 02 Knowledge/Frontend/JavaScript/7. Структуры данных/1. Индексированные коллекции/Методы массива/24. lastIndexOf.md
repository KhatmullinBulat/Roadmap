# 24. lastIndexOf

## Кратко

Возвращает индекс последнего вхождения значения или `-1`.

**Мутирует исходный массив:** нет
**Возвращает:** индекс (`number`) или `-1`

## Синтаксис

```js
lastIndexOf(searchElement)
lastIndexOf(searchElement, fromIndex)
```

## Главное

```js
const fruits = ["Яблоко", "Апельсин", "Яблоко"]

console.log(fruits.lastIndexOf("Яблоко")) // 2
console.log(fruits.lastIndexOf("Апельсин")) // 1
console.log(["a", "b"].lastIndexOf("c")) // -1
```

- Ищет с конца, но возвращает обычный индекс с начала.
- `fromIndex` задаёт, с какого индекса начать поиск назад.

## Ограничения и типичные ошибки

- Для `NaN` так же бесполезен, как `indexOf`.
- На практике чаще нужен `findLastIndex`.

## Практика

- [ ] Ограничить поиск через `fromIndex`
