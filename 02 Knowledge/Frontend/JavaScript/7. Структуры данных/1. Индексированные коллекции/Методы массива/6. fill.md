# 6. fill

## Кратко

Заполняет часть или весь массив одним значением, заменяя существующие элементы.

**Мутирует исходный массив:** да
**Возвращает:** изменённый (тот же самый) массив

## Синтаксис

```js
fill(value)
fill(value, start)
fill(value, start, end)
```

## Главное

```js
const zeros = new Array(3).fill(0)
console.log(zeros) // [0, 0, 0]

const partial = [1, 2, 3, 4].fill("x", 1, 3)
console.log(partial) // [1, "x", "x", 4]
```

- `start` включается, `end` — нет.
- Отрицательные индексы считаются с конца.
- `new Array(n).fill(0)` — стандартный способ создать массив нулей.

## Ограничения и типичные ошибки

- `fill` кладёт **одну ссылку**: `new Array(3).fill([])` даст три ссылки на один массив.
- В отличие от `map`/`forEach`, `fill` заполняет и пустые слоты.

## Практика

- [ ] Создать `new Array(3).fill([])` и показать общую ссылку
- [ ] Заполнить массив нулей и попробовать изменить один элемент
- [ ] Заменить `new Array(n).fill(null)` на `Array.from({ length: n }, () => null)`
