# 19. reduceRight

## Кратко

Работает как `reduce()`, но проходит массив справа налево.

**Мутирует исходный массив:** нет
**Возвращает:** аккумулятор итогового типа

## Синтаксис

```js
reduceRight(callbackFn)
reduceRight(callbackFn, initialValue)
```

## Главное

```js
const nested = [[1, 2], [3, 4], [5, 6]]

const flat = nested.reduceRight((acc, cur) => acc.concat(cur), [])
console.log(flat) // [1, 2, 3, 4, 5, 6]

const words = ["мир", "всем"]
console.log(words.reduceRight((acc, w) => `${acc} ${w}`))
// "всем мир"
```

- Порядок важен, когда результат зависит от порядка объединения.
- `index` остаётся настоящим индексом, несмотря на обход с конца.

## Ограничения и типичные ошибки

- На обычных массивах нужен редко.
- Легко спутать направление обхода с направлением результата.
