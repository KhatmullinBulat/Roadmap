# 31. sort

## Кратко

Сортирует массив на месте; без функции сравнения элементы сортируются как строки.

**Мутирует исходный массив:** да
**Возвращает:** тот же самый массив

## Синтаксис

```js
sort()
sort(compareFn)
```

## Главное

```js
const fruits = ["Груша", "Яблоко", "Апельсин"]
fruits.sort()
console.log(fruits) // ["Апельсин", "Груша", "Яблоко"]

const nums = [10, 9, 1]
console.log(nums.sort()) // [1, 10, 9] — по строкам!
console.log(nums.sort((a, b) => a - b)) // [1, 9, 10]
```

- По умолчанию сравнивает `String(a) < String(b)`.
- Сортировка стабильна с ECMAScript 2019.
- Для строк — `(a, b) => a.localeCompare(b, "ru")`.

## Ограничения и типичные ошибки

- Мутирует массив — для копии `toSorted()` или `[...arr].sort()`.
- Без компаратора числа идут лексикографически.
