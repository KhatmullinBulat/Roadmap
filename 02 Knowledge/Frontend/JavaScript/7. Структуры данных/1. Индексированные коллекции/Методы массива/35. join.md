# 35. join

## Кратко

Объединяет элементы массива в строку через заданный разделитель.

**Мутирует исходный массив:** нет
**Возвращает:** строку

## Синтаксис

```js
join()
join(separator)
```

## Главное

```js
const words = ["Привет", "мир"]

console.log(words.join(" ")) // "Привет мир"
console.log(words.join()) // "Привет,мир"
console.log(words.join("")) // "Приветмир"
console.log([].join("-")) // ""
```

- По умолчанию разделитель — запятая.
- `null` и `undefined` дают пустую строку.
- Без аргумента ведёт себя как `toString()`.

## Ограничения и типичные ошибки

- Пустой массив даёт пустую строку, а не разделитель.
- Вложенные массивы разворачиваются на один уровень.
