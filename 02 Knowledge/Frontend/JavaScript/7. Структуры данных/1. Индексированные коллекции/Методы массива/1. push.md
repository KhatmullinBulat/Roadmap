# 1. push

## Кратко

Добавляет один или несколько элементов в конец массива и возвращает новую длину.

**Мутирует исходный массив:** да
**Возвращает:** новую длину массива (`number`)

## Синтаксис

```js
push(element1, …, elementN)
```

## Главное

```js
const fruits = ["Яблоко", "Апельсин"]
const count = fruits.push("Груша")

console.log(fruits) // ["Яблоко", "Апельсин", "Груша"]
console.log(count) // 3
```

- Принимает любое количество аргументов — можно добавить сразу несколько элементов.
- Зеркален `unshift()`, но действует с конца.

## Ограничения и типичные ошибки

- Возвращает длину, а не массив: `arr.push(x).push(y)` бросит ошибку.
- `arr.push(...hugeArray)` на очень большом массиве может переполнить стек.
- Мутирует массив; для копии — `[...arr, item]`.

## Практика

- [ ] Добавить несколько элементов одним вызовом и проверить возвращённую длину
- [ ] Сделать независимую копию через spread и убедиться, что исходный массив не изменился
- [ ] Сравнить `push` и `concat` по влиянию на исходный массив
