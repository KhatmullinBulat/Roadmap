# 7. copyWithin

## Кратко

Копирует часть массива внутри него самого, не меняя длину.

**Мутирует исходный массив:** да
**Возвращает:** изменённый (тот же самый) массив

## Синтаксис

```js
copyWithin(target)
copyWithin(target, start)
copyWithin(target, start, end)
```

## Главное

```js
const arr = [1, 2, 3, 4, 5]

arr.copyWithin(0, 3) // копирует [4, 5] в начало
console.log(arr) // [4, 5, 3, 4, 5]
```

- `target` — куда копировать, `start`/`end` — откуда.
- Длина массива не меняется.

## Ограничения и типичные ошибки

- В прикладном коде нужен редко — потребитель низкоуровневых алгоритмов.
- Отрицательные индексы легко запутать, проверяйте результат на маленьком массиве.
