# 22. includes

## Кратко

Проверяет наличие значения в массиве, корректно находя `NaN`.

**Мутирует исходный массив:** нет
**Возвращает:** `true` или `false`

## Синтаксис

```js
includes(searchElement)
includes(searchElement, fromIndex)
```

## Главное

```js
const nums = [1, 2, NaN]

console.log(nums.includes(2)) // true
console.log(nums.includes(NaN)) // true
console.log([1, 2].indexOf(NaN)) // -1 — для сравнения
```

- Использует `SameValueZero`: `NaN` находится, `+0` и `-0` равны.
- Начинает поиск с `fromIndex`; отрицательное значение считается с конца.

## Ограничения и типичные ошибки

- Не даёт позиции элемента — для этого `indexOf`.
- Приведение типов не делается: `[1].includes("1")` — `false`.
