# 28. findLastIndex

## Кратко

Возвращает индекс последнего элемента, удовлетворяющего условию, или `-1`.

**Мутирует исходный массив:** нет
**Возвращает:** индекс (`number`) или `-1`

## Синтаксис

```js
findLastIndex(callbackFn)
findLastIndex(callbackFn, thisArg)
```

## Главное

```js
const nums = [1, 2, 3, 4]

console.log(nums.findLastIndex((n) => n % 2 === 0)) // 3
console.log(nums.findLastIndex((n) => n > 10)) // -1
```

- Появился в ES2023.
- Удобен для удаления через `splice`.

## Ограничения и типичные ошибки

- Проверяйте `-1` перед `splice`/`at`.
- Старым средам нужен полифилл.
