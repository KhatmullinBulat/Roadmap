# 14. values

## Кратко

Возвращает итератор значений массива.

**Мутирует исходный массив:** нет
**Возвращает:** Array Iterator со значениями

## Синтаксис

```js
values()
```

## Главное

```js
const fruits = ["Яблоко", "Апельсин"]

for (const fruit of fruits.values()) {
  console.log(fruit) // "Яблоко", затем "Апельсин"
}

console.log([...fruits.values()]) // ["Яблоко", "Апельсин"]
```

- Равен `arr[Symbol.iterator]()`, поэтому `for...of` по массиву вызывает именно его.
- Итератор ленивый и не создаёт копию массива.

## Ограничения и типичные ошибки

- Итератор одноразовый.
- Для массива нужен `[...arr.values()]` или `Array.from()`.

## Практика

- [ ] Собрать `values()` в массив и сравнить с исходным
- [ ] Обойти массив через `for...of` и через `values()`
- [ ] Показать, что второй проход по итератору пуст
