# 29. toSorted

## Кратко

Возвращает новую отсортированную копию массива, не меняя исходный.

**Мутирует исходный массив:** нет
**Возвращает:** новый отсортированный массив

## Синтаксис

```js
toSorted()
toSorted(compareFn)
```

## Главное

```js
const nums = [10, 1, 5]

const sorted = nums.toSorted((a, b) => a - b)
console.log(sorted) // [1, 5, 10]
console.log(nums) // [10, 1, 5] — не изменён
```

- Появился в ES2023.
- Без компаратора сортирует как строки.
- Аналог `[...arr].sort()`.

## Ограничения и типичные ошибки

- Не путайте с `sort()`, который мутирует массив.
- Требует полифилла в старых браузерах.
