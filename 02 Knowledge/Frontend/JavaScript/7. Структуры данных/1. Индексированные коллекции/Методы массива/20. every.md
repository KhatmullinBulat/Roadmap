# 20. every

## Кратко

Проверяет, что все элементы удовлетворяют условию.

**Мутирует исходный массив:** нет
**Возвращает:** `true` или `false`

## Синтаксис

```js
every(callbackFn)
every(callbackFn, thisArg)
```

## Главное

```js
const ages = [22, 18, 30]

console.log(ages.every((age) => age >= 18)) // true
console.log(ages.every((age) => age > 25)) // false
```

- Похож на квантор «для всех».
- Прекращает обход на первом ложном элементе.

## Ограничения и типичные ошибки

- `[].every(...) === true` — частая причина багов.
- Пропускает пустые слоты.

## Практика

- [ ] Проверить, что `[].every(...)` возвращает `true`
- [ ] Написать проверку, что все числа больше нуля
- [ ] Сравнить `every` и `some` на пустом массиве
