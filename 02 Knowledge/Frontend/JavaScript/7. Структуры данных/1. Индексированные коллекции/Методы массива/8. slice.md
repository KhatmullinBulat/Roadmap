# 8. slice

## Кратко

Возвращает поверхностную копию части массива от `start` до `end` (не включая `end`).

**Мутирует исходный массив:** нет
**Возвращает:** новый массив

## Синтаксис

```js
slice()
slice(start)
slice(start, end)
```

## Главное

```js
const fruits = ["Яблоко", "Апельсин", "Груша", "Лимон"]

console.log(fruits.slice(1, 3)) // ["Апельсин", "Груша"]
console.log(fruits.slice(-2)) // ["Груша", "Лимон"]
console.log(fruits.slice()) // поверхностная копия всего массива
```

- Без аргументов — копия массива.
- Отрицательные значения — отсчёт с конца.
- Если `end` меньше `start`, вернётся пустой массив.

## Ограничения и типичные ошибки

- Копия поверхностная: вложенные объекты остаются общими.
- Не путайте со `splice`, который мутирует массив.

## Практика

- [ ] Получить последние три элемента через отрицательный индекс
- [ ] Скопировать массив и изменить копию, показав независимость
- [ ] Проверить, что `slice(0)` — новый массив, а не `[]`
