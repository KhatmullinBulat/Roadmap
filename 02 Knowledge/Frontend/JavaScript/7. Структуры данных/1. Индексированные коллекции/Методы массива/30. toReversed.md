# 30. toReversed

## Кратко

Возвращает новую копию массива в обратном порядке.

**Мутирует исходный массив:** нет
**Возвращает:** новый развёрнутый массив

## Синтаксис

```js
toReversed()
```

## Главное

```js
const nums = [1, 2, 3]

console.log(nums.toReversed()) // [3, 2, 1]
console.log(nums) // [1, 2, 3]
```

- Появился в ES2023.
- Аналог `[...arr].reverse()`.
- Сохраняет дыры так же, как `reverse`.

## Ограничения и типичные ошибки

- Имя легко перепутать с `reverse()`, который мутирует.
- Полифилл для старых сред.

## Практика

- [ ] Развернуть массив, не меняя исходный
- [ ] Получить последний элемент как `arr.toReversed()[0]`
- [ ] Сравнить с `reverse`
