# 2. pop

## Кратко

Удаляет последний элемент массива и возвращает его.

**Мутирует исходный массив:** да
**Возвращает:** удалённый элемент или `undefined` для пустого массива

## Синтаксис

```js
pop()
```

## Главное

```js
const fruits = ["Яблоко", "Апельсин", "Груша"]

const last = fruits.pop()
console.log(last) // "Груша"
console.log(fruits) // ["Яблоко", "Апельсин"]
```

- Уменьшает `length` на 1.
- Вместе с `push()` реализует стек (LIFO).

## Ограничения и типичные ошибки

- `undefined` — законный результат и для пустого массива, и для массива с `undefined` в конце.
- Мутирует массив; для копии — `arr.slice(0, -1)` или `arr.toSpliced(-1, 1)`.

## Практика

- [ ] Очистить массив через `while (arr.length) arr.pop()`
- [ ] Использовать `push`/`pop` как стек в небольшой задаче
- [ ] Проверить, что `[].pop()` не бросает ошибку
