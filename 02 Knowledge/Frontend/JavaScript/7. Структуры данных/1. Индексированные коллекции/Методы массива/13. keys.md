# 13. keys

## Кратко

Возвращает итератор индексов массива.

**Мутирует исходный массив:** нет
**Возвращает:** Array Iterator с индексами

## Синтаксис

```js
keys()
```

## Главное

```js
const fruits = ["Яблоко", "Апельсин", "Груша"]

for (const index of fruits.keys()) {
  console.log(index) // 0, 1, 2
}

console.log([...fruits.keys()]) // [0, 1, 2]
```

- Итератор одноразовый: повторный `for...of` ничего не выведет.
- Есть также у `Map`, `Set` и TypedArray.

## Ограничения и типичные ошибки

- `keys()` возвращает индексы, а не ключи свойств — не путайте с `Object.keys()`.
- Для дыр индексы всё равно перечисляются.
