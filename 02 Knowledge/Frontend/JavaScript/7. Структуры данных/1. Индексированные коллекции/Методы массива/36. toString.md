# 36. toString

## Кратко

Возвращает строковое представление массива — элементы через запятую.

**Мутирует исходный массив:** нет
**Возвращает:** строку

## Синтаксис

```js
toString()
```

## Главное

```js
const nums = [1, 2, 3]

console.log(nums.toString()) // "1,2,3"
console.log(String(nums)) // "1,2,3" — то же самое
console.log([].toString()) // ""
```

- Не принимает аргументов.
- Вызывается при неявном приведении: `${arr}` и `arr + "!"`.
- Пустые слоты дают пустые строки: `[1, , 3].toString()` → `"1,,3"`.

## Ограничения и типичные ошибки

- Вложенные массивы выводятся без скобок — легко перепутать структуру.
- Для читаемого вывода используйте `JSON.stringify`.
