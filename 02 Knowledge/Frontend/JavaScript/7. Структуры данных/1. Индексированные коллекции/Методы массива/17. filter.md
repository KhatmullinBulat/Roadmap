# 17. filter

## Кратко

Создаёт новый массив из элементов, для которых функция вернула `true`.

**Мутирует исходный массив:** нет
**Возвращает:** новый массив, возможно короче исходного

## Синтаксис

```js
filter(callbackFn)
filter(callbackFn, thisArg)
```

## Главное

```js
const numbers = [1, 2, 3, 4, 5]

const even = numbers.filter((n) => n % 2 === 0)
console.log(even) // [2, 4]
```

- Колбэк может вернуть любое truthy-значение.
- Пропускает пустые слоты в разреженных массивах.
- Часто комбинируется с `map`.

## Ограничения и типичные ошибки

- `filter(Boolean)` убирает `0`, `""`, `null`, `undefined`, `NaN`, `false` — иногда это не то, что нужно.
- Сначала `filter`, потом `map` — обычно выгоднее по производительности.

## Практика

- [ ] Убрать `null` и `undefined` через `filter(Boolean)`
- [ ] Оставить только чётные числа и удвоить их
- [ ] Сравнить `filter().map()` и `flatMap()`
