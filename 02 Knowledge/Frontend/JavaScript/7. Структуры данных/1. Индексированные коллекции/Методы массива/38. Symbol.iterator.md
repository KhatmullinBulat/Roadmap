# 38. Symbol.iterator

## Кратко

Возвращает итератор по умолчанию, благодаря которому работают `for...of`, spread и деструктуризация.

**Мутирует исходный массив:** нет
**Возвращает:** итератор (обычно он же `values()`)

## Синтаксис

```js
[Symbol.iterator]()
```

## Главное

```js
const [a, b] = [1, 2, 3]
console.log(a, b) // 1 2

console.log([...new Set([1, 2, 2])]) // [1, 2]

const arr = [1, 2]
console.log(arr[Symbol.iterator] === arr.values) // true
```

- Именно этот символ использует `for...of`.
- В разреженных массивах дыры превращаются в `undefined`.

## Ограничения и типичные ошибки

- Итератор одноразовый.
- Собственный `[Symbol.iterator]` делает итерируемым любой класс.
