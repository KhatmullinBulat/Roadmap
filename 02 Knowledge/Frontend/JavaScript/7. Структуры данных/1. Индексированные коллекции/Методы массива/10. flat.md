# 10. flat

## Кратко

Разворачивает вложенные массивы на указанную глубину и возвращает новый массив.

**Мутирует исходный массив:** нет
**Возвращает:** новый массив

## Синтаксис

```js
flat()
flat(depth)
```

## Главное

```js
const nested = [1, [2, [3, [4]]]]

console.log(nested.flat()) // [1, 2, [3, [4]]]
console.log(nested.flat(2)) // [1, 2, 3, [4]]
console.log(nested.flat(Infinity)) // [1, 2, 3, 4]
```

- По умолчанию глубина `1`.
- `Infinity` полностью разворачивает массив.
- Удаляет пустые слоты (дыры).

## Ограничения и типичные ошибки

- `flat(0)` возвращает копию без изменений.
- `flat(Infinity)` на больших данных — дорогая операция.
