# 16. map

## Кратко

Создаёт новый массив, применяя функцию к каждому элементу.

**Мутирует исходный массив:** нет
**Возвращает:** новый массив той же длины

## Синтаксис

```js
map(callbackFn)
map(callbackFn, thisArg)
```

## Главное

```js
const numbers = [1, 2, 3]

const doubled = numbers.map((n) => n * 2)
console.log(doubled) // [2, 4, 6]
console.log(numbers) // [1, 2, 3] — исходный не изменён
```

- Колбэк получает `(element, index, array)`.
- Длина результата всегда равна длине исходного массива.

## Ограничения и типичные ошибки

- `map` никогда не сокращает длину массива.
- Если функция ничего не возвращает, получится массив `undefined`.
- Для побочных эффектов используйте `forEach`.
