# 26. findIndex

## Кратко

Возвращает индекс первого элемента, удовлетворяющего условию, или `-1`.

**Мутирует исходный массив:** нет
**Возвращает:** индекс (`number`) или `-1`

## Синтаксис

```js
findIndex(callbackFn)
findIndex(callbackFn, thisArg)
```

## Главное

```js
const users = [{ id: 1 }, { id: 2 }]

console.log(users.findIndex((u) => u.id === 2)) // 1
console.log(users.findIndex((u) => u.id === 99)) // -1
```

- Прекращает обход на первом найденном.
- Может найти `NaN`, в отличие от `indexOf`.

## Ограничения и типичные ошибки

- `-1` — «не найдено», проверяйте именно его: `0` — валидный индекс.
- Если нужен сам элемент, используйте `find`.

## Практика

- [ ] Найти индекс объекта по свойству
- [ ] Не путать индекс `0` с «не найдено»
- [ ] Найти `NaN` через `findIndex`
