# 34. reverse

## Кратко

Разворачивает массив на месте и возвращает его.

**Мутирует исходный массив:** да
**Возвращает:** тот же самый массив

## Синтаксис

```js
reverse()
```

## Главное

```js
const nums = [1, 2, 3]

console.log(nums.reverse()) // [3, 2, 1]
console.log(nums) // [3, 2, 1] — изменён
```

- Мутирует исходный массив.
- Для копии — `toReversed()` или `[...arr].reverse()`.
- Сохраняет пустые слоты.

## Ограничения и типичные ошибки

- `sort().reverse()` — не «сортировка по убыванию», а обратный порядок.
- В цепочках легко потерять предсказуемый порядок равных элементов.
