# 4. shift

## Кратко

Удаляет первый элемент массива и возвращает его.

**Мутирует исходный массив:** да
**Возвращает:** удалённый элемент или `undefined` для пустого массива

## Синтаксис

```js
shift()
```

## Главное

```js
const fruits = ["Яблоко", "Апельсин", "Груша"]

const first = fruits.shift()
console.log(first) // "Яблоко"
console.log(fruits) // ["Апельсин", "Груша"]
```

- Сдвигает все индексы на единицу влево.
- Вместе с `push()` реализует очередь (FIFO).

## Ограничения и типичные ошибки

- `shift()` в цикле по большому массиву даёт `O(n²)`.
- Мутирует массив; для копии — `arr.slice(1)`.

## Практика

- [ ] Реализовать очередь через `push`/`shift` на пяти элементах
- [ ] Убрать `shift()` из цикла и сравнить сложность
- [ ] Проверить, что возвращает `[].shift()`
