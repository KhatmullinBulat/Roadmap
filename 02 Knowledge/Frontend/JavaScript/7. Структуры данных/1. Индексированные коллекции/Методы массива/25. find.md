# 25. find

## Кратко

Возвращает первый элемент, удовлетворяющий условию, или `undefined`.

**Мутирует исходный массив:** нет
**Возвращает:** найденный элемент или `undefined`

## Синтаксис

```js
find(callbackFn)
find(callbackFn, thisArg)
```

## Главное

```js
const users = [{ id: 1, name: "Анна" }, { id: 2, name: "Борис" }]

console.log(users.find((u) => u.id === 2)) // { id: 2, name: "Борис" }
console.log(users.find((u) => u.id === 99)) // undefined
```

- Прекращает обход на первом найденном элементе.
- Колбэк получает `(element, index, array)`.

## Ограничения и типичные ошибки

- Результат может быть `undefined` — проверяйте перед доступом к свойствам.
- Для поиска примитива `includes` проще.

## Практика

- [ ] Найти объект по свойству и безопасно обработать `undefined`
- [ ] Сравнить `find` и `filter(...)[0]`
- [ ] Показать, что `find` на пустом массиве не бросает ошибку
