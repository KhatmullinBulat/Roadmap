# 21. some

## Кратко

Возвращает `true`, если хотя бы один элемент удовлетворяет условию.

**Мутирует исходный массив:** нет
**Возвращает:** `true` или `false`

## Синтаксис

```js
some(callbackFn)
some(callbackFn, thisArg)
```

## Главное

```js
const numbers = [1, 2, 3]

console.log(numbers.some((n) => n > 2)) // true
console.log(numbers.some((n) => n > 10)) // false
console.log([].some(Boolean)) // false
```

- Прекращает обход на первом подходящем элементе.
- `some(Boolean)` проверяет наличие truthy-значения.

## Ограничения и типичные ошибки

- Для проверки наличия конкретного значения проще `includes()`.
- `filter(...).length > 0` медленнее, чем `some`.

## Практика
