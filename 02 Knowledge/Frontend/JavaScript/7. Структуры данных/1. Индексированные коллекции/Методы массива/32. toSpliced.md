# 32. toSpliced

## Кратко

Возвращает копию массива с изменённой частью, не меняя исходный.

**Мутирует исходный массив:** нет
**Возвращает:** новый массив

## Синтаксис

```js
toSpliced(start, deleteCount, item1, …, itemN)
```

## Главное

```js
const months = ["Январь", "Март", "Апрель"]

const fixed = months.toSpliced(1, 0, "Февраль")
console.log(fixed) // ["Январь", "Февраль", "Март", "Апрель"]
console.log(months) // ["Январь", "Март", "Апрель"]
```

- Появился в ES2023.
- Те же правила индексов, что у `splice`.
- Поддерживает отрицательные индексы.

## Ограничения и типичные ошибки

- В отличие от `splice`, не возвращает удалённые элементы.
- Требует полифилла.

## Практика

- [ ] Вставить элемент в середину без мутации
- [ ] Заменить `splice` на `toSpliced` в известном коде
- [ ] Показать, что исходный массив не изменился
