# 37. toLocaleString

## Кратко

Вызывает `toLocaleString` у каждого элемента и собирает их через разделитель локали.

**Мутирует исходный массив:** нет
**Возвращает:** строку, зависящую от локали

## Синтаксис

```js
toLocaleString()
toLocaleString(locales)
toLocaleString(locales, options)
```

## Главное

```js
const prices = [1000, 2000]

console.log(prices.toLocaleString("ru-RU")) // "1 000,2 000"

const dates = [new Date(2026, 10, 6)]
console.log(dates.toLocaleString("ru-RU")) // "06.11.2026, 00:00:00"
```

- У каждого элемента вызывается `toLocaleString(locales, options)`.
- Для чисел и дат даёт формат, учитывающий язык.

## Ограничения и типичные ошибки

- Для массива строк разницы с `toString` почти нет.
- До ES2018 локальный разделитель не был согласован между средами.
