# 11. flatMap

## Кратко

Применяет функцию к каждому элементу и разворачивает результат на один уровень.

**Мутирует исходный массив:** нет
**Возвращает:** новый массив

## Синтаксис

```js
flatMap(callbackFn)
flatMap(callbackFn, thisArg)
```

## Главное

```js
const words = ["Привет мир", "Добрый день"]

console.log(words.flatMap((s) => s.split(" ")))
// ["Привет", "мир", "Добрый", "день"]

console.log(words.map((s) => s.split(" ")))
// [["Привет", "мир"], ["Добрый", "день"]]
```

- Эквивалент `map(...).flat()` с глубиной `1`.
- Исходный массив не меняется.
- Удобен для «один ко многим» — фильтр и преобразование за один проход.

## Ограничения и типичные ошибки

- Глубина только `1`.
- Пустые массивы в результате просто исчезают — это заменяет фильтрацию.
