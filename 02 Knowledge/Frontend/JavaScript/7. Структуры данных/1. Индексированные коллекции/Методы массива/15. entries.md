# 15. entries

## Кратко

Возвращает итератор пар `[индекс, значение]`.

**Мутирует исходный массив:** нет
**Возвращает:** Array Iterator с парами `[index, value]`

## Синтаксис

```js
entries()
```

## Главное

```js
const fruits = ["Яблоко", "Апельсин"]

for (const [index, fruit] of fruits.entries()) {
  console.log(index, fruit) // 0 "Яблоко"; 1 "Апельсин"
}

console.log([...fruits.entries()]) // [[0, "Яблоко"], [1, "Апельсин"]]
```

- Каждая пара — обычный массив из двух элементов.
- Удобно совмещать с деструктуризацией.
- У `Map` пары — `[ключ, значение]`.

## Ограничения и типичные ошибки

- Итератор одноразовый.
- Если массив не нужен, `forEach((value, index) => ...)` проще.

## Практика

- [ ] Вывести элементы с индексами через `entries()`
- [ ] Собрать `entries()` в массив и разобрать деструктуризацией
- [ ] Применить `Object.fromEntries()` к результату
