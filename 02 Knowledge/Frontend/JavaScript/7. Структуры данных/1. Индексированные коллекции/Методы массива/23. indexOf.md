# 23. indexOf

## Кратко

Возвращает индекс первого вхождения значения или `-1`, если его нет.

**Мутирует исходный массив:** нет
**Возвращает:** индекс (`number`) или `-1`

## Синтаксис

```js
indexOf(searchElement)
indexOf(searchElement, fromIndex)
```

## Главное

```js
const fruits = ["Яблоко", "Апельсин", "Яблоко"]

console.log(fruits.indexOf("Апельсин")) // 1
console.log(fruits.indexOf("Груша")) // -1
console.log(fruits.indexOf("Яблоко", 1)) // 2
```

- Сравнение строгое (`===`).
- Второй аргумент задаёт стартовый индекс.

## Ограничения и типичные ошибки

- `NaN` не находится.
- Для проверки наличия лучше `includes`.

## Практика

- [ ] Найти все вхождения через цикл с `fromIndex`
- [ ] Проверить `indexOf` на `NaN`
