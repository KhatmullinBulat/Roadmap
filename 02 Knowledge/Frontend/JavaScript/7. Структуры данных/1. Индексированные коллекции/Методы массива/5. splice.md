# 5. splice

## Кратко

Удаляет, добавляет или заменяет элементы по указанному индексу и возвращает массив удалённых элементов.

**Мутирует исходный массив:** да
**Возвращает:** массив удалённых элементов (возможно пустой)

## Синтаксис

```js
splice(start)
splice(start, deleteCount)
splice(start, deleteCount, item1, …, itemN)
```

## Главное

```js
const months = ["Январь", "Март", "Апрель", "Май"]

const removed = months.splice(1, 0, "Февраль") // вставка
console.log(months) // ["Январь", "Февраль", "Март", "Апрель", "Май"]
console.log(removed) // []

months.splice(0, 1) // удаление
console.log(months) // ["Февраль", "Март", "Апрель", "Май"]
```

- `start` может быть отрицательным — отсчёт с конца.
- Если `deleteCount` не указан, удаляется всё от `start` до конца.
- При `deleteCount = 0` элементы только вставляются.

## Ограничения и типичные ошибки

- `splice` мутирует, `slice` копирует — частое заблуждение.
- Удаление в цикле по возрастающим индексам пропускает элементы — идите с конца.
- Операция в середине массива — `O(n)`.

## Практика

- [ ] Вставить элемент в середину, ничего не удаляя
- [ ] Удалить элементы начиная с отрицательного индекса
- [ ] Заменить `splice` на `toSpliced` и убедиться, что исходный массив не меняется
