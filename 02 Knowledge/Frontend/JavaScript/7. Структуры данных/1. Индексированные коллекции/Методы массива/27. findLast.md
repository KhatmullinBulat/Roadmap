# 27. findLast

## Кратко

Возвращает последний элемент, удовлетворяющий условию, или `undefined`.

**Мутирует исходный массив:** нет
**Возвращает:** найденный элемент или `undefined`

## Синтаксис

```js
findLast(callbackFn)
findLast(callbackFn, thisArg)
```

## Главное

```js
const logs = [
  { level: "info", msg: "старт" },
  { level: "error", msg: "сбой" },
  { level: "error", msg: "повтор" },
]

console.log(logs.findLast((l) => l.level === "error").msg) // "повтор"
console.log([1, 2].findLast((n) => n > 5)) // undefined
```

- Появился в ES2023.
- Обход идёт с конца.
- Для первого совпадения — `find`.

## Ограничения и типичные ошибки

- Нужен полифилл для старых сред.
- Проверяйте `undefined` перед доступом к свойствам.
