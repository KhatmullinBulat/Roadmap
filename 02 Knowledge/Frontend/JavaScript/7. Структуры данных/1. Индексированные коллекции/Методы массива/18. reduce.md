# 18. reduce

## Кратко

Последовательно сводит элементы массива к одному значению через аккумулятор.

**Мутирует исходный массив:** нет
**Возвращает:** аккумулятор итогового типа

## Синтаксис

```js
reduce(callbackFn)
reduce(callbackFn, initialValue)
```

## Главное

```js
const numbers = [1, 2, 3, 4]

const sum = numbers.reduce((acc, n) => acc + n, 0)
console.log(sum) // 10

const grouped = ["Анна", "Антон", "Борис"].reduce((acc, name) => {
  const letter = name[0]
  ;(acc[letter] ??= []).push(name)
  return acc
}, {})
```

- Колбэк получает `(accumulator, currentValue, index, array)`.
- С `initialValue` обход начинается с первого элемента, без него — со второго.
- Через `reduce` можно реализовать `map`, `filter` и `flat` — хорошее упражнение.

## Ограничения и типичные ошибки

- Без `initialValue` на пустом массиве — `TypeError`.
- Не смешивайте мутирующий и чистый стиль аккумулятора.
