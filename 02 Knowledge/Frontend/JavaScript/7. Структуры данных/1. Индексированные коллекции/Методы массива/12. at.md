# 12. at

## Кратко

Возвращает элемент по индексу, поддерживая отрицательные индексы с конца.

**Мутирует исходный массив:** нет
**Возвращает:** элемент или `undefined`

## Синтаксис

```js
at(index)
```

## Главное

```js
const fruits = ["Яблоко", "Апельсин", "Груша"]

console.log(fruits.at(0)) // "Яблоко"
console.log(fruits.at(-1)) // "Груша"
console.log(fruits.at(-2)) // "Апельсин"
console.log(fruits.at(10)) // undefined
```

- Появился в ES2022.
- Без аргумента работает как `at(0)`.
- Есть также у строк и TypedArray.

## Ограничения и типичные ошибки

- `fruits[-1]` — обычный ключ `"-1"`, а не последний элемент.
- Не быстрее `arr[i]`, это только удобство.

## Практика

- [ ] Получить последний элемент через `at(-1)` вместо `arr[arr.length - 1]`
- [ ] Проверить поведение на пустом массиве
- [ ] Сравнить `at(-1)` и `arr[-1]` в консоли
