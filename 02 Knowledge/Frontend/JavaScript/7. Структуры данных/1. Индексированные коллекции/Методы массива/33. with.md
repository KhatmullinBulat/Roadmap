# 33. with

## Кратко

Возвращает копию массива, в которой заменён элемент по индексу.

**Мутирует исходный массив:** нет
**Возвращает:** новый массив

## Синтаксис

```js
with(index, value)
```

## Главное

```js
const nums = [1, 2, 3]

console.log(nums.with(1, 20)) // [1, 20, 3]
console.log(nums) // [1, 2, 3]
console.log(nums.with(-1, 30)) // [1, 2, 30]
```

- Появился в ES2023.
- Поддерживает отрицательные индексы.
- Бросает `RangeError` для индекса вне границ.

## Ограничения и типичные ошибки

- Не путайте с устаревшей конструкцией `with`.
- В отличие от `arr[i] = x`, не меняет исходный массив.

## Практика

- [ ] Заменить последний элемент без мутации
- [ ] Проверить `RangeError` для несуществующего индекса
- [ ] Сравнить `with` с `[...arr]` и присваиванием
