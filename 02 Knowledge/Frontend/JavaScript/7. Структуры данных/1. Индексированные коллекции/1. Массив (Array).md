# Массив (Array)

## Кратко

`Array` — встроенный объект для упорядоченной коллекции: элементы доступны по целочисленному индексу с нуля, а `length` отражает количество слотов. В отличие от объекта массив умеет сохранять порядок и предоставляет десятки методов: `push`, `map`, `filter`, `reduce`, `sort` и другие. В JavaScript массив — частный случай объекта со ссылочной семантикой.

## Главное

Объекты позволяют хранить данные со строковыми ключами. Но довольно часто нам необходима *упорядоченная коллекция* данных, в которой присутствуют 1-й, 2-й, 3-й элементы и т.д. Например, она понадобится нам для хранения списка чего-либо: пользователей, товаров, элементов HTML и т.д.

В этом случае объект использовать неудобно, так как он не предоставляет методов управления порядком элементов. Для хранения упорядоченных коллекций существует особая структура данных, которая называется массив, `Array`.

### Создание

```js
let arr = new Array()
let arr = []
```

В основном используется второй вариант. В скобках можно указать начальные значения элементов:
```js
let fruits = ["Яблоко", "Апельсин", "Слива"]
```

Осторожно с `new Array(n)`: один числовой аргумент — это длина, а не элемент.

```js
new Array(3) // [ <3 empty items> ], length = 3
new Array(3).length // 3
Array.of(3) // [3] — один элемент
Array(3, 4) // [3, 4]
```

### Доступ к элементам

Элементы массива нумеруются, начиная с нуля. Элемент можно получить, указав его номер в квадратных скобках:
```js
let fruits = ["Яблоко", "Апельсин", "Слива"]

console.log(fruits[0]) // Яблоко
console.log(fruits[1]) // Апельсин
console.log(fruits[2]) // Слива
```
Элемент можно заменить:
```js
fruits[2] = "Груша" // теперь ["Яблоко", "Апельсин", "Груша"]
```
...Или добавить новый к существующему массиву:
```js
fruits[3] = "Лимон" // теперь ["Яблоко", "Апельсин", "Груша", "Лимон"]
```

Обращение к несуществующему индексу возвращает `undefined`, но не бросает ошибку:
```js
fruits[10] // undefined
fruits[-1] // undefined — отрицательный индекс не работает напрямую
fruits.at(-1) // "Лимон" — с конца
```

### `length`

Общее число элементов содержится в его свойстве `length`:
```js
let fruits = ["Яблоко", "Апельсин", "Слива"]

console.log(fruits.length) // 3
```

`length` — это не «количество элементов», а длина числовой последовательности. Менять его можно, и это влияет на массив:

```js
const arr = [1, 2, 3, 4, 5]
arr.length = 2 // [1, 2] — хвост обрезан
arr.length = 4 // [1, 2, <2 empty items>] — появились пустые слоты
arr.length = -1 // RangeError: Invalid array length
```

`length` — всегда целое от `0` до `2**32 - 1`. Значение больше — `RangeError`.

### Разные типы внутри

В массиве могут храниться элементы любого типа:
```js
// разные типы значений
let arr = ["Яблоко", {name: "Булат"}, true, function() { alert("привет") }]

// получить элемент с индексом 1 (объект) и затем показать его свойство
console.log(arr[1].name) // Булат

// получить элемент с индексом 3 (функция) и выполнить ее
arr[3]() // привет
```

Современный TypeScript и просто аккуратный код обычно держат массив однородным: `string[]` или `User[]`. Смешанный массив `Array<string | number>` делает методы вроде `sort()` менее предсказуемыми.

### Внутреннее устройство массива

Массив — это особый подвид объектов. Квадратные скобки, используемые для того, чтобы получить доступ к элементу `arr[0]` — это по сути обычный синтаксис доступа по ключу, как `obj[key]`, где в роли `obj` у нас `arr`, а в качестве ключа — числовой индекс.

Массивы расширяют объекты, так как предусматривают специальные методы для работы с упорядоченными коллекциями данных, а также свойство `length`. Но в основе все равно лежит объект.

Массив является объектом и, следовательно, ведет себя как объект. Например, копируется по ссылке:
```js
let fruits = ["Банан"]
let arr = fruits // две переменные ссылаются на один и тот же массив

console.log(arr === fruits) // true

arr.push("Груша") // массив меняется по ссылке
console.log(fruits) // Банан, Груша — теперь два элемента
```

Движок JavaScript старается хранить элементы массива в непрерывной области памяти, один за другим. Но они утратят эффективность, если перестать работать с массивом как с "упорядоченной коллекцией данных" и начнем использовать его как обычный объект.
```js
// создаем массив
let fruits = []

// создаем свойство с индексом, намного превышающим длину массива
fruits[99999] = 5

// создаем свойство с произвольным именем
fruits.age = 22
```
Варианты неправильного применения массива:
- Добавление нечислового свойства, например: `arr.test = 5`
- Создание "дыр", например: добавление `arr[0]`, затем `arr[1000]` (между ними ничего нет)
- Заполнение массива в обратном порядке, например: `arr[1000]`, `arr[999]` и т.д.

Внутри V8 такой массив переключается из «быстрого» режима (packed elements) в «словарный» (dictionary mode), и доступ к элементам замедляется.

### Проверка на массив

```js
Array.isArray([]) // true
Array.isArray({ length: 0 }) // false — не фейковый «массивоподобный» объект
typeof [] // "object" — бесполезно
[] instanceof Array // true, но ломается между iframe/realm
```

### Массивоподобные объекты

`Array.from()` превращает в массив любые объекты с `length` и индексами — `arguments`, `NodeList`, строку, `Set`, `Map`:

```js
Array.from("abc") // ["a", "b", "c"]
Array.from(new Set([1, 2, 2])) // [1, 2]
Array.from({ length: 3 }, (_, i) => i) // [0, 1, 2]
[...document.querySelectorAll("li")] // реальный массив
```

### Копирование

Объекты и массивы копируются по ссылке. Чтобы получить независимую копию:

```js
const shallow = [...arr] // поверхностная копия
const shallow2 = arr.slice()
const deep = structuredClone(arr) // глубокая копия

const alsoRef = arr // не копия
```

`slice()`, spread и `concat()` дают **поверхностную** копию: элементы-объекты внутри остаются общими. Для глубокой копии — `structuredClone()` или библиотека.

### Дыры (sparse arrays) и методы

Если оставить «дыры», часть методов их пропускает, а часть — нет:

```js
const sparse = [1, , 3] // length = 3, индекс 1 пуст

sparse[1] // undefined
1 in sparse // false — индекса 1 вообще нет
sparse.map((x) => x * 2) // [2, <1 empty item>, 6] — колбэк не зовётся для пустого слота
[...sparse] // [1, undefined, 3] — дыра становится undefined
Array.from(sparse) // [1, undefined, 3]
```

`forEach`, `map`, `filter`, `some`, `every`, `find` пропускают пустые слоты. `keys()`, `entries()` и spread видят их как `undefined`.

### Итерация

```js
const items = ["a", "b", "c"]

for (const item of items) { /* значения */ }
for (const [i, item] of items.entries()) { /* индекс и значение */ }

items.forEach((item, i) => console.log(i, item))
```

`for...in` по массиву — плохая идея: он обходит и строковые свойства, и унаследованные. `for...of` использует `Symbol.iterator` и корректно работает с дырами.

### Полезные методы по задачам

| Задача | Метод |
| --- | --- |
| добавить / удалить в конец | `push` / `pop` |
| добавить / удалить в начало | `unshift` / `shift` |
| вырезать часть | `slice` (без мутации), `splice` (с мутацией) |
| найти элемент | `find`, `findIndex`, `indexOf`, `includes` |
| преобразовать каждый элемент | `map` |
| оставить подходящие | `filter` |
| свернуть к одному значению | `reduce` / `reduceRight` |
| проверить условие | `some` / `every` |
| сортировать | `sort` (мутирует), `toSorted` (копия) |
| развернуть | `reverse` (мутирует), `toReversed` (копия) |
| разобрать вложенность | `flat`, `flatMap` |
| группировать | `Object.groupBy` |

Каждому методу — отдельная заметка в разделе «Методы массива».

### Производительность

- `push`/`pop` в конец — амортизированно `O(1)`.
- `unshift`/`shift` — `O(n)`: сдвигают все индексы.
- `splice` в середину — `O(n)`.
- `includes`, `indexOf`, `find` — `O(n)`.
- `sort` — обычно `O(n log n)`.
- Для частых поисков по ключу используйте `Set` или `Map`, а не `includes` в цикле (получится `O(n²)`).
