# 1. Что такое движок JavaScript

## Кратко

Движок JavaScript — это программа, которая разбирает и исполняет код: реализует ECMAScript и оптимизирует «горячие» участки JIT-компиляцией. DOM, сеть и файлы в него не входят — их добавляет окружение (браузер или Node.js).

## Главное

**Движок JavaScript** — программа, которая исполняет код JavaScript. Он реализует стандарт ECMAScript и обычно входит в состав браузера или среды выполнения. Сам по себе движок не предоставляет DOM, файловую систему или сетевые API: их добавляет окружение.

Примеры движков:
- [[2. V8|V8]] — Chrome, Chromium-браузеры и Node.js;
- [[3. SpiderMonkey|SpiderMonkey]] — Firefox;
- JavaScriptCore — Safari;
- Chakra — устаревший движок Internet Explorer.

Упрощённо работа движка выглядит так:
1. Он разбирает исходный код и проверяет его синтаксис.
2. Создаёт внутреннее представление программы.
3. Выполняет код и при необходимости компилирует часто выполняемые участки в машинный код.
4. Во время работы собирает статистику и применяет оптимизации; если предположения об оптимизации перестают выполняться, может отменить её.

Такая стратегия называется JIT-компиляцией (*just-in-time*). Конкретная архитектура различается у движков, но общий принцип один: сохранить быстрый запуск и ускорять горячий код без предварительной компиляции разработчиком.

### Этапы обработки кода

| Этап | Что происходит |
| --- | --- |
| Лексический анализ | код разбивается на токены |
| Парсинг | строится AST — дерево синтаксиса |
| Байткод | AST компилируется в промежуточное представление, его исполняет интерпретатор |
| Профилирование | движок наблюдает, какие функции и типы встречаются чаще всего |
| Оптимизация (JIT) | «горячий» код компилируется в машинный с отдельных допущениях о типах |
| Деоптимизация | если допущение нарушено, оптимизированный код отбрасывается и берётся из интерпретатора |

### Почему это важно прикладному разработчику

- **Мономорфность**: стабильные типы свойств одного объекта помогают движку держать оптимизации; смешение строк и чисел в одном поле вызывает деоптимизацию.
- **Формы объектов (hidden classes)**: свойства лучше объявлять при создании объекта, а не добавлять потом в разном порядке.
- **Сборка мусора**: движок освобождает недостижимые значения; удержание больших структур в замыканиях или глобальных переменных мешает этому.

### Кто где встроен

- **V8** — Chrome, Edge, Opera, Node.js, Deno;
- **SpiderMonkey** — Firefox;
- **JavaScriptCore** (Nitro) — Safari;
- **Hermes** — React Native;
- **QuickJS**, **Boa** — небольшие и исследовательские движки.
