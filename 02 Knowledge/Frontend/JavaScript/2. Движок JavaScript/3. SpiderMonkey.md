# 3. SpiderMonkey

## Кратко

SpiderMonkey — открытый движок JavaScript от Mozilla и первый движок языка: он создан в 1995 году для Netscape, а сегодня исполняет JS в Firefox. Он реализует ECMAScript с JIT-компиляцией, но, как и другие движки, не даёт браузерных API.

## Главное

**SpiderMonkey** — движок JavaScript с открытым исходным кодом, который разрабатывает Mozilla. Это первый в истории движок JavaScript: Брендан Эйх написал его для Netscape в 1995 году. Сегодня SpiderMonkey используется в Firefox и может встраиваться в другие приложения.

Как и другие современные движки, SpiderMonkey реализует ECMAScript, использует интерпретацию и JIT-компиляцию, а также самостоятельно управляет памятью. Он не предоставляет DOM, `window` или другие браузерные API: эти возможности создаёт Firefox как окружение вокруг движка.

Названия компонентов и стратегий оптимизации движка со временем меняются, поэтому в учебной заметке важнее помнить его роль: SpiderMonkey исполняет JavaScript в Firefox и не является самим браузером.

### Чем помнить

- Первый движок JavaScript, написанный в Netscape за несколько дней в 1995 году.
- Код открыт под MPL 2.0; движок встроен не только в Firefox, но и в Thunderbird и другие проекты.
- Как и V8, использует интерпретатор и несколько уровней JIT-компиляции; конкретные названия компонентов часто менялись.
- Отличается от браузера так же, как движок — от рантайма: DOM, `window` и Web API предоставляет Firefox (Gecko).

Сравнение с другими движками:

| Движок | Проект | Где используется |
| --- | --- | --- |
| SpiderMonkey | Mozilla | Firefox, Thunderbird |
| V8 | Google | Chrome, Edge, Node.js, Deno |
| JavaScriptCore | Apple | Safari, WebKit |
| Chakra | Microsoft | старый Edge и Internet Explorer |
