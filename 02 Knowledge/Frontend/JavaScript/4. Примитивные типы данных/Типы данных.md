Тип данных определяет, какие значения бывают в программе и какие операции с ними допустимы. JavaScript — динамически типизированный язык: тип принадлежит значению, а не переменной. Одно и то же имя в разное время может ссылаться на значения разных типов.
```js
let value = 42
value = "готово"
value = true
```

Стандарт [[3. ECMAScript|ECMAScript]] определяет восемь типов:

- семь примитивных: `undefined`, `null`, `boolean`, `number`, `bigint`, `string`, `symbol`;
- `object` — тип объектов.

Примитивное значение не изменяется «на месте». Любая операция создаёт новое значение, а переменной можно присвоить результат.
```js
let title = "js"
title = title.toUpperCase()
```

Функции технически являются объектами, но `typeof` возвращает для них отдельную строку `"function"`. Для `null` `typeof` исторически возвращает `"object"`; это известная особенность языка, а не признак того, что `null` — объект.

| Тип                  | Пример      | `typeof`      |
| -------------------- | ----------- | ------------- |
| [[Undefined]]        | `undefined` | `"undefined"` |
| [[Null]]             | `null`      | `"object"`    |
| [[Boolean]]          | `true`      | `"boolean"`   |
| [[Number]]           | `42`, `NaN` | `"number"`    |
| [[BigInt]]           | `42n`       | `"bigint"`    |
| [[String]]           | `"текст"`   | `"string"`    |
| [[Symbol]]           | `Symbol()`  | `"symbol"`    |
| [[1. Object Object]] | `"object"`  | `{}`, `[]`    |

`typeof` полезен для грубой проверки типов, но не различает массив, дату и обычный объект. Для массива используйте `Array.isArray()`, а для собственных свойств объекта — `Object.hasOwn()`.
