`undefined` — примитивное значение, которое обычно означает «значение отсутствует». Оно появляется, когда JavaScript ещё не получил результат.
```js
let user
console.log(user) // undefined

function logMessage() {
  console.log("готово")
}
console.log(logMessage()) // undefined
```

`undefined` также возвращается при чтении несуществующего свойства объекта или элемента массива за его границами.
```js
const settings = {}
console.log(settings.theme) // undefined
```

Не стоит присваивать `undefined` вручную, чтобы «очистить» переменную. Если нужно явно обозначить отсутствие известного значения, обычно используют [[Null|null]]. Так различается ситуация «значение не было задано» и «мы намеренно указали отсутствие значения».

Для проверки используйте строгое сравнение или nullish-операторы:
```js
if (value === undefined) {}
const label = value ?? "не задано"
```

`typeof undeclaredName` — особый безопасный случай: он вернёт `"undefined"` даже для необъявленного имени. Однако это не работает для переменной `let` или `const` во временной мёртвой зоне — там будет `ReferenceError`.
