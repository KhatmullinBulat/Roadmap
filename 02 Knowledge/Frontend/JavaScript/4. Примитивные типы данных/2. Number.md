# Number

## Кратко

`number` — единственный числовой примитив: и целые числа, и дроби двойной точности по стандарту IEEE 754, плюс `Infinity` и `NaN`. Из-за этого дробные вычисления бывают неточными, безопасные целые ограничены диапазоном `±(2 ** 53 - 1)`, а для большей точности есть [[3. BigInt]].

## Главное

`number` представляет и целые числа, и числа с плавающей точкой двойной точности. Отдельного типа для целых чисел в JavaScript нет.
```js
const count = 42
const price = 12.5
```

Из-за формата IEEE 754 десятичные дроби иногда нельзя представить точно:
```js
0.1 + 0.2 === 0.3 // false
```

Для денежных расчётов обычно хранят сумму в минимальных единицах (`kopecks`, `cents`) или используют специальную библиотеку десятичных чисел, если этого требует задача.

### Специальные значения
- `Infinity` и `-Infinity` — бесконечности; например, `1 / 0` даёт `Infinity`.
- `NaN` (*Not a Number*) — результат некорректной числовой операции. Любая арифметика с `NaN` обычно тоже возвращает `NaN`.
- `-0` и `0` различаются в некоторых операциях, хотя `-0 === 0` равно `true`.

```js
Number.isNaN(NaN) // true
Number.isFinite(42) // true
Object.is(-0, 0) // false
```

Целые числа безопасны в диапазоне от `Number.MIN_SAFE_INTEGER` до `Number.MAX_SAFE_INTEGER` включительно: от `-(2 ** 53 - 1)` до `2 ** 53 - 1`. За его пределами не каждое целое число представимо точно.
```js
Number.MAX_SAFE_INTEGER + 1 === Number.MAX_SAFE_INTEGER + 2 // true
```

Для произвольной точности целых чисел существует [[3. BigInt]]. Не путайте `Number.MIN_VALUE` с самым отрицательным числом: это наименьшее положительное число, которое можно представить. Самое большое конечное значение — `Number.MAX_VALUE`.

### Разбор и проверка чисел

```js
Number("42") // 42
Number("42px") // NaN — строгий разбор всей строки
Number("") // 0
Number(true) // 1

parseInt("42px", 10) // 42 — читает до первого нечислового символа
parseFloat("3.14вау") // 3.14

Number.isNaN("abc") // false — строка это не NaN, это не число
isNaN("abc") // true — old global isNaN приводит аргумент к числу
```

Совет: для данных пользователя используйте `parseInt(value, 10)` с явным основанием и `Number.isFinite()`, если нужно убедиться, что число конечное. Глобальный `isNaN()` приводит аргумент к числу и часто даёт неверный ответ.

### Сравнение дробей и денег

```js
0.1 + 0.2 // 0.30000000000000004
Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON // true

// деньги — в минимальных единицах
const priceInCents = 1999
const total = priceInCents * 3 / 100 // 59.97
```

Для сравнения дробей используют допуск (`Number.EPSILON` или свой), для денег — целые минимальные единицы или `Intl.NumberFormat`, а для сложных финансовых задач — библиотеку десятичных чисел.

### Форматирование

```js
(1234.5).toFixed(2) // "1234.50"
(1234).toLocaleString("ru-RU") // "1 234"
new Intl.NumberFormat("ru-RU", { style: "currency", currency: "RUB" })
  .format(1999) // "1 999,00 ₽"
```

Вывод форматированных чисел на экран — задача `Intl`, а не ручной склейки строк.
