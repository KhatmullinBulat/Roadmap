# Типы данных

## Кратко

В JavaScript восемь типов: семь примитивов (`undefined`, `null`, `boolean`, `number`, `bigint`, `string`, `symbol`) и `object` для объектов. Язык динамически типизирован: тип принадлежит значению, а не переменной, поэтому одно имя может хранить значения разных типов.

## Главное

Тип данных определяет, какие значения бывают в программе и какие операции с ними допустимы. JavaScript — динамически типизированный язык: тип принадлежит значению, а не переменной. Одно и то же имя в разное время может ссылаться на значения разных типов.
```js
let value = 42
value = "готово"
value = true
```

Стандарт [[3. ECMAScript|ECMAScript]] определяет восемь типов:

- семь примитивных: `undefined`, `null`, `boolean`, `number`, `bigint`, `string`, `symbol`;
- `object` — тип объектов.

Примитивное значение не изменяется «на месте». Любая операция создаёт новое значение, а переменной можно присвоить результат.
```js
let title = "js"
title = title.toUpperCase()
```

Функции технически являются объектами, но `typeof` возвращает для них отдельную строку `"function"`. Для `null` `typeof` исторически возвращает `"object"`; это известная особенность языка, а не признак того, что `null` — объект.

| Тип                     | Пример                       | `typeof`                  | Что хранит                     |
| ----------------------- | ---------------------------- | ------------------------- | ------------------------------ |
| [[6. Undefined]]           | `undefined`                  | `"undefined"`             | значение не задано             |
| [[7. Null]]                | `null`                       | `"object"`                | намеренное отсутствие значения |
| [[4. Boolean]]             | `true`, `false`              | `"boolean"`               | логическое значение            |
| [[2. Number]]              | `42`, `NaN`, `Infinity`      | `"number"`                | числа двойной точности         |
| [[3. BigInt]]              | `42n`                        | `"bigint"`                | целые произвольной точности    |
| [[5. String]]              | `"текст"`                    | `"string"`                | строка                         |
| [[8. Symbol]]              | `Symbol()`                   | `"symbol"`                | уникальный идентификатор       |
| [[1. Object \| Object]] | `{}`, `[]`, `function () {}` | `"object"` / `"function"` | объекты, массивы, функции      |

`typeof` полезен для грубой проверки типов, но не различает массив, дату и обычный объект. Для массива используйте `Array.isArray()`, а для собственных свойств объекта — `Object.hasOwn()`.

### Примитивы и объекты: хранение значений

Примитивы хранятся «по значению», а объекты — по ссылке. Сравнение двух объектов проверяет ссылки, а не содержимое:
```js
"js" === "js" // true
{ a: 1 } === { a: 1 } // false

const a = { x: 1 }
const b = a
a.x = 2
b.x // 2 — это тот же объект
```

### Обёртки над примитивами

У примитивов есть методы, потому что при обращении к свойству движок временно «оборачивает» примитив в объект (`String`, `Number`, `Boolean`). Это не тип самого значения, а механизм доступа.

```js
"javascript".length // 10
let name = "Bulat"
name.length // 6
```

Не создавайте обёртки через `new String()`: это уже объект, и он ведёт себя иначе при сравнении и в условиях.
