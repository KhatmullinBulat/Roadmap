# Boolean

## Кратко

`boolean` — логический тип с двумя значениями, `true` и `false`. В условиях любое значение неявно приводится к нему: ложными считаются только `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined` и `NaN`, всё остальное — истинно.

## Главное

`boolean` — примитивный тип с двумя значениями: `true` и `false`. Его используют для состояний и результатов проверок.
```js
const isLoggedIn = true
const hasAccess = user.role === "admin"
```

В условии JavaScript неявно преобразует любое значение к логическому. Ложными (*falsy*) считаются только:
```js
false, 0, -0, 0n, "", null, undefined, NaN
```

Все остальные значения истинны (*truthy*), в том числе пустые массивы, пустые объекты и строка `"false"`.
```js
Boolean([]) // true
Boolean("false") // true
```

Явно преобразовать значение можно через `Boolean(value)` или двойное отрицание `!!value`. Второй вариант короче, но первый обычно легче читать.
```js
const hasName = Boolean(user.name)
```

Не используйте `new Boolean(false)`. Это объект, а любой объект является truthy, поэтому `if (new Boolean(false))` выполнится.

### Truthy/falsy подвохи

```js
Boolean([]) // true
Boolean({}) // true
Boolean("0") // true — непустая строка
Boolean(" ") // true — пробел это символ

Boolean(NaN) // false
Boolean(-0) // false
```

Частая ошибка — проверять массив через `if (arr)` и считать, что пустой массив «ложный». Для массивов и строк проверяйте длину явно: `arr.length > 0`.

```js
const items = []
if (items) console.log("выполнится") // массив всегда truthy
if (items.length) console.log("не выполнится")
```

### Короткое замыкание

**Короткое замыкание** (short-circuit evaluation) в JavaScript — это поведение логических операторов (`&&` — И, `||` — ИЛИ, а также `??` — оператор нулевого слияния), при котором вычисление прекращается досрочно, как только результат становится понятным.

#### Оператор И (`&&`)

Вычисляет операнды слева направо и **останавливается на первом ложном (falsy) значении**, возвращая его. Если все значения истинные (truthy), возвращает последний операнд.
```js
console.log(false && "привет") // false (остановился на false)
console.log(0 && "привет")     // 0 (0 — falsy)
console.log("мир" && "привет") // "привет" (оба truthy, вернул последнее)
```
Краткая замена `if`:
```js
const user = { name: "Иван" }
// Выыполнит функцию print() только если user существует
user && print(user.name)
```

#### Оператор ИЛИ (`||`)

Вычисляет операнды слева направо и **останавливается на первом истинном (truthy) значении**, возвращая его. Если все значения ложные, возвращает последнее.
```js
console.log(true || "привет") // true
console.log("" || "привет")   // "привет" (пустая строка — falsy)
console.log(0 || false || 10) // 10
```
*Практическое применение* (значения по умолчанию):
```js
const name = user.name || "Гость"
// Если user.name пустой, null или undefined, переменная name получит "Гость"
```

#### Оператор нулевого слияния (`??`)

Работает похоже на `||`, но останавливается только тогда, когда слева находится строго `null` или `undefined` (в отличие от `||`, который срабатывает и на `0`, `""` или `false`).
```js
console.log(0 ?? 42)        // 0 (потому что 0 — это не null/undefined)
console.log(null ?? 42)     // 42
console.log("" ?? "default) // ""
```
