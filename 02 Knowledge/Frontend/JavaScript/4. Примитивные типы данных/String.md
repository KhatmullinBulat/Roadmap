`string` — примитивный тип для текстовых данных. Строку создают одинарными, двойными или обратными кавычками. Обратные кавычки позволяют вставлять выражения и записывать многострочный текст.
```js
const name = "Bulat"
const greeting = `Привет, ${name}!`
```

Строки неизменяемы: нельзя заменить один символ в существующей строке. Методы возвращают новую строку.
```js
const source = "javascript"
const result = source.toUpperCase()

console.log(source) // "javascript"
console.log(result) // "JAVASCRIPT"
```

Индексация и `length` работают с кодовыми единицами UTF-16, а не всегда с видимыми символами. Поэтому символы вне базовой плоскости Unicode, например часть эмодзи, могут занимать две кодовые единицы. Для обхода строки по кодовым точкам используйте `for...of` или `[...text]`.
```js
const emoji = "🙂"
console.log(emoji.length) // 2
console.log([...emoji].length) // 1
```

Часто используемые операции: `includes()`, `startsWith()`, `slice()`, `replace()`, `split()`, `trim()`, `toLowerCase()` и `toUpperCase()`. Не создавайте строки через `new String()` — это объект-обёртка, который ведёт себя иначе при сравнении и проверке истинности. Для преобразования значения в строку используйте `String(value)` или шаблонную строку.
```js
const text = String(42)
const sameText = `${42}`
```
