# String

## Кратко

`string` — примитив для текста, создаётся одинарными, двойными или обратными кавычками (последние дают шаблонные строки с `${}` и переносами). Строки неизменяемы: методы вроде `toUpperCase()` возвращают новую строку, а `length` и индексы работают с кодовыми единицами UTF-16.

## Главное

`string` — примитивный тип для текстовых данных. Строку создают одинарными, двойными или обратными кавычками. Обратные кавычки позволяют вставлять выражения и записывать многострочный текст.
```js
const name = "Bulat"
const greeting = `Привет, ${name}!`
```

Строки неизменяемы: нельзя заменить один символ в существующей строке. Методы возвращают новую строку.
```js
const source = "javascript"
const result = source.toUpperCase()

console.log(source) // "javascript"
console.log(result) // "JAVASCRIPT"
```

Индексация и `length` работают с кодовыми единицами UTF-16, а не всегда с видимыми символами. Поэтому символы вне базовой плоскости Unicode, например часть эмодзи, могут занимать две кодовые единицы. Для обхода строки по кодовым точкам используйте `for...of` или `[...text]`.
```js
const emoji = "🙂"
console.log(emoji.length) // 2
console.log([...emoji].length) // 1
```

Часто используемые операции: `includes()`, `startsWith()`, `slice()`, `replace()`, `split()`, `trim()`, `toLowerCase()` и `toUpperCase()`. Не создавайте строки через `new String()` — это объект-обёртка, который ведёт себя иначе при сравнении и проверке истинности. Для преобразования значения в строку используйте `String(value)` или шаблонную строку.
```js
const text = String(42)
const sameText = `${42}`
```

### Шаблонные строки

```js
const user = { name: "Bulat", age: 22 }
const profile = `Имя: ${user.name}
Возраст: ${user.age}`

const sum = `${1 + 2}` // "3"
```

Внутри `${}` можно писать любое выражение, вызывать функции и обращаться к свойствам. Вложенные шаблоны (тегированные шаблоны) используются редко, но встречаются в библиотеках вроде `styled-components` и `graphql-tag`.

### Сравнение и сортировка

```js
"Apple" < "apple" // true — сравнение по кодам UTF-16, а не по алфавиту
"я" > "a" // true — кириллица стоит после латиницы в Unicode

const names = ["Анна", "Борис"]
names.sort((a, b) => a.localeCompare(b, "ru")) // сортировка по правилам языка
```

Для сортировки и сравнения длинных текстов с буквами разных языков используйте `localeCompare`, а для регистронезависимого сравнения — `toLowerCase()` или `Intl.Collator`.

### Регулярные выражения

Методы `match()`, `replace()`, `replaceAll()` и `split()` принимают регулярные выражения:
```js
"2026-11-06".replace(/(\d{4})-(\d{2})-(\d{2})/, "$3.$2.$1") // "06.11.2026"
```
