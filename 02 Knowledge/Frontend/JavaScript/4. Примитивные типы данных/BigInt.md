`bigint` — примитивный тип для целых чисел произвольной точности. Он нужен, когда `number` выходит за безопасный целочисленный диапазон `±(2 ** 53 - 1)`.
```js
const id = 9_007_199_254_740_993n
const huge = 123456789012345678901234567890n
```

Литерал `BigInt` оканчивается на `n`. Также значение можно создать через `BigInt()`, если входное значение можно преобразовать в целое.
```js
const count = BigInt("9007199254740993")
```

`number` и `bigint` нельзя смешивать в арифметических операциях без явного преобразования:
```js
// 1n + 1 // TypeError
1n + BigInt(1) // 2n
```

У `BigInt` нет дробной части; деление округляет результат к нулю. Он не подходит для бесконечности и `NaN`, а большинство функций `Math` не принимают `BigInt`.
```js
5n / 2n // 2n
```

Выбирайте `BigInt` только когда нужна точность больших целых значений: например, для идентификаторов, криптографии или счётчиков. Для обычных чисел и дробей используйте [[Number]].
