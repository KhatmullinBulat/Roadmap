# BigInt

## Кратко

`bigint` — примитив для целых чисел произвольной точности, записывается с суффиксом `n` (`42n`). Он нужен, когда значение выходит за безопасный диапазон `number`, но не поддерживает дроби, `NaN`, `Infinity` и не смешивается с `number` в арифметике без явного преобразования.

## Главное

`bigint` — примитивный тип для целых чисел произвольной точности. Он нужен, когда `number` выходит за безопасный целочисленный диапазон `±(2 ** 53 - 1)`.
```js
const id = 9_007_199_254_740_993n
const huge = 123456789012345678901234567890n
```

Литерал `BigInt` оканчивается на `n`. Также значение можно создать через `BigInt()`, если входное значение можно преобразовать в целое.
```js
const count = BigInt("9007199254740993")
```

`number` и `bigint` нельзя смешивать в арифметических операциях без явного преобразования:
```js
// 1n + 1 // TypeError
1n + BigInt(1) // 2n
```

У `BigInt` нет дробной части; деление округляет результат к нулю. Он не подходит для бесконечности и `NaN`, а большинство функций `Math` не принимают `BigInt`.
```js
5n / 2n // 2n
```

Выбирайте `BigInt` только когда нужна точность больших целых значений: например, для идентификаторов, криптографии или счётчиков. Для обычных чисел и дробей используйте [[2. Number]].

### Что поддерживается и что нет

```js
typeof 1n // "bigint"
10n ** 20n // 100000000000000000000n
-5n / 2n // -2n — округление к нулю
5n % 2n // 1n

1n == 1 // true — нестрогое равенство
1n === 1 // false — разные типы

Number(2n) // 2
BigInt(2.5) // RangeError — дробь не преобразуется
```

Ограничения:
- нельзя передавать в `Math` и `JSON.stringify()` без преобразования;
- нельзя использовать в `Array.prototype`-методах, ожидающих `number`, без конвертации;
- нет `NaN`, `Infinity` и десятичных дробей — для них остаётся `Number`.

```js
JSON.stringify({ id: 1n }) // TypeError
String(1n) // "1"
```

При передаче `BigInt` по сети обычно сериализуют в строку, а на клиенте восстанавливают через `BigInt(str)`.
