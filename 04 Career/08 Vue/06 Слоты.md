# Слоты: default, named, scoped

## Краткий ответ (30 секунд)

**Слот** — «дырка» в шаблоне компонента, куда родитель кладёт разметку. `<slot />` — **default** (без имени), `<slot name="header" />` — **named** (родитель пишет `<template #header>`). **Scoped slot** — когда компонент **отдаёт данные** в переданную родителем разметку: `<slot :item="item" />`, а родитель пишет `<template #default="{ item }">`. Это главная замена «рендер-пропсов» из React: логика списка/состояния — в компоненте, разметка элемента — у родителя.

## Подробно

### Default-слот

```vue
<!-- Card.vue -->
<article class="card">
  <slot>Пустая карточка</slot>
</article>
```

```vue
<Card>Контент</Card>
```

Фолбэк (`Пустая карточка`) показывается, если слот не передан.

### Named-слоты

```vue
<!-- Modal.vue -->
<div class="modal">
  <header><slot name="header" /></header>
  <main><slot /></main>
  <footer><slot name="footer">OK</slot></footer>
</div>
```

```vue
<Modal>
  <template #header><h2>Заголовок</h2></template>
  Текст
  <template #footer><button>Сохранить</button></template>
</Modal>
```

Синтаксис: `v-slot:header` или `#header`.

### Scoped-слоты

```vue
<!-- DataList.vue -->
<script setup>
defineProps<{ items: { id: number; name: string }[] }>();
</script>
<template>
  <ul>
    <li v-for="(item, index) in items" :key="item.id">
      <slot :item="item" :index="index" />
    </li>
  </ul>
</template>
```

```vue
<DataList :items="users">
  <template #default="{ item }">
    <strong>{{ item.name }}</strong>
  </template>
</DataList>
```

- Компонент контролирует список (пустое состояние, ключи, стили), родитель — вид строки.
- Можно комбинировать: `<slot name="row" :item="item" />`.
- Проверка «передан ли слот»: `$slots.header` / `useSlots()` (не путать с фолбэком).

### Dynamic slots

```vue
<component :is="layout.component">
  <template #[layout.slot]>...</template>
</component>
```

### Прокидывание слотов

```vue
<!-- Обёртка над DataList -->
<DataList v-bind="$attrs">
  <template #default="slotProps">
    <slot v-bind="slotProps" />
  </template>
</DataList>
```

Полезно для HOC-подобных обёрток, но многоуровневое прокидывание — сигнал усложнения.

### Слоты и `Teleport`/`Transition`

Слоты передают компоненты, которые могут использовать `Teleport` внутри — редко, но возможно. `Transition` вокруг слота требует одного корневого элемента.

### Частые ошибки

- `<template v-slot>` без имени — работает только для default.
- Передача пропсов в default-слот вместо `slot`-props.
- Много `$slots`/`useSlots` для условий — лучше явно передавать `withHeader`-проп или использовать фолбэк.
- Перерендер родителя заново создаёт содержимое слота — не «оптимизирует» (это нормально, если данные меняются).

> [!tip] Как отвечать
> «Слот — это исходящая разметка. Named — точки композиции, scoped — данные наружу (`:item`). Scoped-слоты заменяют render props: список рендерит компонент, элементы — родитель».
