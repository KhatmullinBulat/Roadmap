# Адаптивные картинки и изображения

## Краткий ответ (30 секунд)

Современная картинка: **формат** (AVIF/WebP с фолбэком), **размеры** (`srcset` + `sizes` для `img`; `media` для `<picture>`), **явные `width`/`height`** (или `aspect-ratio`) против CLS, **`loading="lazy"`** для ниже первого экрана, **`fetchpriority="high"`** для LCP-картинки (и `preload` для неё), `decoding="async"`, `alt` по смыслу. `<picture>` нужен для **art direction** (разные кропы) и форматов; `srcset` — для плотности/ширины. Не ленивьте LCP-картинку: это ухудшит метрику.

## Подробно

### `img srcset` + `sizes`

```html
<img
  src="fallback.jpg"
  srcset="img-480.jpg 480w, img-800.jpg 800w, img-1200.jpg 1200w"
  sizes="(max-width: 600px) 100vw, (max-width: 1024px) 50vw, 33vw"
  width="800" height="600"
  alt="Кофе на столе"
  loading="lazy" decoding="async"
/>
```

- Браузер выбирает ширину по `sizes` + DPR, скачивает подходящий файл.
- `src` — фолбэк для старых браузеров/краулеров.

### `<picture>` для форматов и art direction

```html
<picture>
  <source type="image/avif" srcset="hero.avif 1x, hero@2x.avif 2x" />
  <source type="image/webp" srcset="hero.webp" />
  <source media="(max-width: 480px)" srcset="hero-mobile.jpg" />
  <img src="hero.jpg" alt="Витрина" width="1200" height="600" />
</picture>
```

- **Первое подходящее `<source>`** выигрывает — порядок важен (AVIF → WebP → JPEG).
- `media` — art direction (другой кроп на мобильном).
- `type` — формат.

### LCP-изображение

```html
<link rel="preload" as="image" href="hero.avif" fetchpriority="high" />
<img src="hero.avif" fetchpriority="high" width="1200" height="600" alt="" />
```

- Не `loading="lazy"` для above-the-fold.
- `fetchpriority="high"` ускоряет загрузку; у неключевых — `low`.
- Фоновая картинка через CSS `background-image` — **не** попадёт в preload автоматически; либо `<img>` с `object-fit`, либо preload вручную.

### CLS

```css
.media { aspect-ratio: 16 / 9; width: 100%; }
.media img { width: 100%; height: 100%; object-fit: cover; }
```

- Явные размеры (или `aspect-ratio`) обязательны — иначе сдвиг при загрузке.
- `object-fit: cover/contain` — вместо искажений.

### Форматы

| Формат | Когда |
|---|---|
| AVIF | лучшее сжатие, поддержка с 2023 в современных браузерах |
| WebP | широкий фолбэк |
| JPEG | фолбэк и «всё остальное» |
| PNG | прозрачность/графика, где потеря качества недопустима |
| SVG | иконки, логотипы (не для фото) |

Генерация: `sharp`, `squoosh`, CDN-оптимизаторы (imgix, Cloudinary), `vite-imagetools`.

### `alt`

- Информативное: краткое описание смысла («График роста продаж за 2024»).
- Декоративное: `alt=""` (не опускать атрибут).
- Не начинать с «картинка/изображение».
- Кнопка-иконка: `<button aria-label="Закрыть"><svg aria-hidden="true">` .

### Частые ошибки

- `loading="lazy"` на LCP-картинке → LCP хуже.
- Нет `width`/`height` → CLS.
- `srcset` без `sizes` → не работает как ожидается.
- `<picture>` с неправильным порядком `source`.
- Гигантские PNG для фото.

> [!tip] Как отвечать
> «Формат + размеры + размерность + приоритет. `srcset`/`sizes` — плотность и ширина, `<picture>` — форматы и art direction. LCP-картинка не ленивая, с `fetchpriority` и preload. Явные размеры — чтобы не было CLS».
