# Флексбокс и грид

## Краткий ответ (30 секунд)

**Flexbox** — **одномерная** раскладка: элементы выстраиваются в одной оси (главной), с выравниванием по поперечной. Для строк навигации, карточек в ряду, центрирования, «прижать к краю». **Grid** — **двумерная**: явные строки и колонки, сетка `grid-template-columns/rows`, позиционирование по линиям/именам областей. Для макетов страницы, галерей, дашбордов. Оба — «content-driven» (flex) и «layout-driven» (grid); в реальности часто используют вместе: Grid — каркас, Flex — внутри компонента.

## Подробно

### Flexbox: оси и выравнивание

```css
.nav {
  display: flex;
  gap: 12px;
  align-items: center;      /* поперечная ось */
  justify-content: space-between; /* главная ось */
}
```

- **`flex-direction`** задаёт главную ось (`row` / `column`).
- `justify-content` — главная ось, `align-items` — поперечная.
- `flex-grow` / `flex-shrink` / `flex-basis` в шорткате `flex`.
  - `flex: 1` = `1 1 0%` — равные доли, базовая 0.
  - `flex: auto` = `1 1 auto` — базовый размер из контента.
  - `flex: none` = `0 0 auto` — не растёт/не сжимается.
- **`min-width: auto`** у flex-элементов — частая причина «текст вылезает»: нужен `min-width: 0`.
- `flex-wrap` — перенос на новую строку.
- `gap` работает в flex, но **не** даёт выравнивания колонок между строками (это Grid).

```css
/* Центрирование — классика сокращённо */
.center { display: grid; place-items: center; }
```

### Grid: сетка

```css
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-areas:
    "sidebar main"
    "sidebar footer";
  gap: 16px;
}

.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
```

- **`fr`** — доли свободного места: `1fr 2fr`.
- **`repeat()`**, `minmax()`, `auto-fill`/`auto-fit`:

```css
/* Адаптивная галерея без медиа-запросов */
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(240px, 1fr));
  gap: 16px;
}
```

- **`grid-auto-flow: dense`** — заполняет дыры (галерея с разными размерами).
- Явная/неявная сетка: `grid-auto-rows` задаёт размер неявных строк.
- Позиционирование: `grid-column: 1 / 3` (по линиям), `span 2`.

### Что выбрать

| Задача | Инструмент |
|---|---|
| Ряд кнопок/навигация | flex |
| Карточка: иконка + текст + кнопка | flex |
| Прижать футер к низу карточки | flex (`margin-top: auto`) |
| Макет страницы header/sidebar/main | grid (areas) |
| Галерея 12 колонок | grid |
| Дашборд с виджетами разного размера | grid |
| Адаптивные карточки без медиа-запросов | grid `auto-fill` |

### Подпорки для старых браузеров почти не нужны

Flexbox и Grid — Baseline с 2017–2020 (Grid в 2017, flex полностью без префиксов). Сейчас их используют без вендорных префиксов; `display: -webkit-box` — легенда.

### Ловушки на собеседовании

1. **`1fr` и `min-width: auto`** — в Grid `1fr` = `minmax(auto, 1fr)`, и длинный контент ломает колонку; решается `minmax(0, 1fr)`.
2. **`justify-content` в Grid** выравнивает **всю сетку**, а не элементы внутри; для элементов — `justify-items`.
3. **`flex: 1` vs `width: 100%`** — понимание grow/shrink/basis.
4. **`gap`** — работает и в flex, и в grid (современные браузеры).
5. **Абсолютно позиционированный** элемент вынимается из flex/grid потока.

> [!tip] Как отвечать
> «Flex — про одну ось и распределение места, Grid — про двумерную сетку и макет страницы. Я использую Grid для каркаса и Flex внутри компонентов; адаптивную галерею — `auto-fill` + `minmax`».
