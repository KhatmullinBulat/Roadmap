# Доступность: формы, клавиатура, экранные читалки

## Краткий ответ (30 секунд)

A11y — не «для слепых», а для всех: клавиатура, мобильные, слабое зрение, временные ограничения. База: **семантика** (см. [[Семантическая верстка]]), **подписи форм** (`<label for>`), **фокус** (`:focus-visible`, видимый, не перехватывать), **tab-порядок** по DOM, **контраст** (4.5:1 для текста), **не только цветом**, **ARIA только когда нужно**, **скипы** (`skip link`), **Escape/Enter** в виджетах. Проверяется автоматически (axe/Lighthouse) и вручную (Tab + скринридер).

## Подробно

### Формы

```html
<label for="email">Email</label>
<input id="email" name="email" type="email"
       autocomplete="email" required
       aria-describedby="email-hint" />
<p id="email-hint">Мы пришлём код подтверждения</p>

<!-- Ошибка рядом и объявляется -->
<input id="email" aria-invalid="true" aria-describedby="email-error" />
<p id="email-error" role="alert">Неверный формат</p>
```

- `label for` ↔ `id` **или** обёртка `<label><input></label>`.
- `autocomplete` — автозаполнение и когнитивная доступность.
- `aria-invalid`, `role="alert"`/`aria-live="polite"` для ошибок.
- Placeholder **не** замена label.

### Клавиатура

| Элемент | Ожидания |
|---|---|
| Кнопка/ссылка | Tab, Enter (ссылка — Enter, кнопка — Enter/Space) |
| Модалка | фокус внутрь, ловушка фокуса, `Escape`, возврат фокуса |
| Меню/комбобокс | стрелки, Home/End, Escape |
| Табы | стрелки, Home/End |
| Дропдаун | стрелки, Enter |

- `tabindex="0"` — в порядок; `tabindex="-1"` — фокусируемо программно, не в порядке.
- **Не** `tabindex > 0` — ломает порядок.
- Видимый фокус обязателен: `:focus-visible { outline: 2px solid; outline-offset: 2px; }`.

### Контраст и цвет

- Текст — 4.5:1, крупный (18.66px bold/24px) — 3:1, UI-элементы — 3:1.
- Не передавать статус только цветом (`aria-label`, текст, иконка).
- `prefers-contrast`, `forced-colors` — поддержка системных настроек.

### ARIA

- `aria-live="polite"` — «мягкие» объявления (тосты, счётчики), `assertive` — срочные.
- `aria-label`/`aria-labelledby` — имя для скринридера.
- `aria-expanded`, `aria-controls`, `aria-selected` — состояния с виджетами.
- **Правило**: нет нативного элемента → ARIA + JS-поведение. Есть нативный → ARIA не нужен.

### Визуальные и моторные

- `prefers-reduced-motion` — выключить анимации.
- Минимальная область нажатия 44×44 (Apple) / 48×48 (Material) / 24 (WCAG 2.2).
- Увеличение текста до 200% без потери контента.

### Инструменты

- Chrome DevTools → Lighthouse a11y, панель Accessibility (дерево).
- `axe` (расширение/`@axe-core/playwright`).
- Скринридеры: NVDA + Firefox (Windows), VoiceOver + Safari (macOS/iOS), TalkBack (Android).
- Ручной тест: **отключить мышь на 15 минут**.

> [!warning] Подвох
> «Сделал `aria-label` на диве — это доступно?» — без `role`, `tabindex` и обработки клавиш **нет**. ARIA меняет только семантику, а не поведение.
