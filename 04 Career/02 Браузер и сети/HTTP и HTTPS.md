# HTTP и HTTPS

## Краткий ответ (30 секунд)

**HTTP** — текстовый протокол без шифрования: любой узел по пути (Wi-Fi, провайдер, прокси) может прочитать и изменить данные. **HTTPS** — тот же HTTP поверх **TLS**: шифрование, проверка целостности и аутентификация сервера через сертификат. Порты по умолчанию: 80 / 443. HTTPS не «другой протокол», а транспорт: прикладной слой остаётся HTTP. Сейчас весь сайт переводят на HTTPS: HSTS, `Secure`-cookies, Service Workers, HTTP/2 в браузерах требуют HTTPS.

## Подробно

### Что даёт TLS

1. **Конфиденциальность** — данные шифруются (AES-GCM, ChaCha20-Poly1305 в TLS 1.3).
2. **Целостность** — MAC/AEAD ловит изменения.
3. **Аутентификация сервера** — сертификат, подписанный доверенным CA; клиент сверяет домен и цепочку.
4. **Опционально** — mutual TLS (клиентский сертификат), когда сервер аутентифицирует клиента.

**Без TLS:**
- пароли и cookie видны в открытом виде;
- MITM может подменить страницу/JS/inject-ить рекламу;
- нет доверия к адресу: ввели `example.com`, ответил кто угодно.

### TLS-рукопожатие (1.2 vs 1.3)

- **TLS 1.2**: 2-RTT, ClientHello → ServerHello+Cert → … → Finished.
- **TLS 1.3**: 1-RTT, убраны уязвимые алгоритмы (RSA-обмен, CBC), поддерживается 0-RTT при повторном соединении. ECH (Encrypted Client Hello) скрывает имя домена от провайдера.

### Сертификат

- Содержит открытый ключ, домены (SAN), срок, издателя.
- Цепочка: сертификат сайта → промежуточный CA → корневой CA (в доверенном хранилище ОС/браузера).
- Просроченный/самоподписанный → предупреждение.
- Let's Encrypt — бесплатные сертификаты с автоматическим продлением (ACME).

### Влияние на производительность

- Сессионные ключи и повторное использование соединения снижают накладные расходы.
- HTTP/2 **требует** TLS в браузерах, иначе падает до HTTP/1.1.
- TLS-терминация на CDN: стоимость шифрования не у клиента.

### Частое заблуждение

> HTTPS не «шифрует всё навсегда»: шифрование лишь на пути между клиентом и сервером. Если прокси/«корпоративный» CA установлен в систему, MITM теоретически возможен (в комментариях к собеседованию это оценивают).

### HSTS

`Strict-Transport-Security: max-age=31536000; includeSubDomains; preload` — браузер больше не ходит по HTTP на этот домен, даже если пользователь ввёл `http://`. `preload` — внесение в список браузера.

> [!tip] Формулировка
> «HTTPS — это HTTP + TLS. Он даёт шифрование, целостность и аутентификацию сервера через сертификат. HTTP/2 в браузерах требует HTTPS, поэтому это ещё и условие производительности».
