# Виды функций и их отличия

## Краткий ответ (30 секунд)

В JS есть: **function declaration** (поднимается целиком, доступна до строки объявления), **function expression** (присваивается имени, поднимается как `undefined`/TDZ), **стрелочная функция** (нет своего `this`/`arguments`, нельзя `new`), **метод объекта** (короткий синтаксис, свой `this`), **асинхронная функция** (возвращает `Promise`), **функция-генератор** (`function*`, возвращает итератор), **классовый метод/generic method**, **IIFE**. Их различия — в hoisting, `this`, `arguments`, возможности `new` и возвращаемом типе.

## Подробно

### 1. Function declaration

```js
sayHi(); // работает — hoisting поднимает функцию целиком

function sayHi() {
  return "hi";
}
```

- Поднимается в начале области видимости, тело доступно до объявления.
- В блоках в strict-режиме ведёт себя блочно.

### 2. Function expression

```js
const sayHi = function () { return "hi"; };
sayHi(); // ок

sayHi2(); // TypeError: sayHi2 is not a function (var) или ReferenceError (const → TDZ)
var sayHi2 = function () { return "hi"; };
```

- Поднимается похоже на переменную: `var` → `undefined`, `const`/`let` → TDZ.
- Может быть анонимной; именованное выражение удобно для рекурсии/стека.

### 3. Стрелочная функция

```js
const add = (a, b) => a + b;
```

- **Нет своего `this`** — берёт из окружения создания.
- **Нет `arguments`** (можно `(...args) => {}`).
- **Нельзя вызвать с `new`**, нельзя использовать как конструктор.
- **Нельзя быть генератором** (`function*`), `yield` внутри стрелки недопустим.
- Свойства `prototype` у стрелки нет.
- `call`/`apply`/`bind` не меняют `this` стрелки.
- Короткое тело без `{}` возвращает значение неявно.

### 4. Методы объекта и класса

```js
const obj = {
  greet() { return "hi"; }, // method shorthand — свой this
};

class A {
  greet() {}        // в A.prototype
  async load() {}   // то же, но возвращает Promise
  static create() {} // на самом конструкторе
  greetAsync = async () => {} // поле-стрелка — подклеено к экземпляру
}
```

Методы класса **не конструируются через `new`** и **не имеют свойства `prototype`**. Поля-стрелки создают новую функцию на каждом экземпляре — это стоит денег по памяти, но сохраняет `this`.

### 5. Async-функции

```js
async function load() {
  return 42; // Promise.resolve(42)
}
```

Всегда возвращают `Promise`, внутренние `throw` — превращаются в rejection. Подробнее — [[Promise и async await]].

### 6. Генераторы

```js
function* range(n) {
  for (let i = 0; i < n; i++) yield i;
}
[...range(3)]; // [0, 1, 2]
```

Подробнее — [[Генераторы и итераторы]].

### 7. IIFE

```js
(function () {
  // своя область видимости
})();
```

До `let`/`const` и модулей использовался для изоляции. Сейчас чаще встречается в UMD-бандлах и в примерах.

### 8. Специальные виды

- **Getter/Setter** — аксессоры в литерале или классе.
- **Классы** — функции, которые нельзя вызвать без `new`.
- **Proxy-функция** — объект с `[[Call]]`.
- **Методы, созданные через `Object.create`** — возвращают объект-прототип.
- **`Function` constructor** — `new Function("a", "return a")`, по сути `eval`, не применять.

### Сводная таблица

| Вид | `this` | `arguments` | `new` | Hoisting | Возвращает |
|---|---|---|---|---|---|
| Declaration | динамический | есть | да | полностью | что вернёт |
| Expression | динамический | есть | да | как переменная | что вернёт |
| Arrow | лексический | нет | нет | как переменная | выражение |
| Метод | динамический | есть | нет | — | что вернёт |
| Async | динамический | есть | нет | как function | `Promise` |
| Generator | динамический | есть | нет | как function | итератор |
| Class | — | — | только `new` | TDZ | экземпляр |

> [!tip] Частый подвох
> «В чём отличие стрелки от обычной функции?» — недостаточно сказать «короче». Полный ответ: `this`, `arguments`, `new`, `prototype`, `yield`.
