## Кратко

Мутирующие методы изменяют исходный массив: `push`, `pop`, `shift`, `unshift`, `splice`, `sort`, `reverse`, `fill`, `copyWithin`.

Немутирующие методы не изменяют исходный массив: `map`, `filter`, `slice`, `concat`, `flat`, `flatMap`, `toSorted`, `toReversed`, `toSpliced`, `with`. Также к ним относятся методы поиска и проверки вроде `find`, `some`, `every`, `includes`.

## 1. Мутирующие методы

**Мутирующие методы (mutating)** изменяют исходный массив. То есть они работают с ним напрямую, не создавая новую копию.

| Метод                             | Что делает                                               |
| --------------------------------- | -------------------------------------------------------- |
| [[1. push \| push()]]             | Добавляет элементы в конец массива                       |
| [[2. pop \| pop()]]               | Удаляет последний элемент                                |
| [[3. unshift \| unshift()]]       | Добавляет элементы в начало массива                      |
| [[4. shift \| shift()]]           | Удаляет первый элемент                                   |
| [[5. splice \| splice()]]         | Добавляет, удаляет или заменяет элементы                 |
| [[31. sort \| sort()]]            | Сортирует массив                                         |
| [[34. reverse \| reverse()]]      | Разворачивает порядок элементов                          |
| [[6. fill \| fill()]]             | Заполняет массив указанным значением                     |
| [[7. copyWithin \| copyWithin()]] | Копирует часть массива в другую позицию этого же массива |
### Пример
```js
const numbers = [1, 2, 3]

numbers.push(4)

console.log(numbers) // [1, 2, 3, 4]
```
Метод `push()` изменил исходный массив.


## Немутирующие методы

**Немутирующие методы (non-mutating)** не изменяют исходный массив. Они либо возвращают новый массив, либо возвращают другое значение.

| Метод                              | Что делает                                                 |
| ---------------------------------- | ---------------------------------------------------------- |
| [[16. map \| map()]]               | Создает новый массив, преобразуя каждый элемент            |
| [[17. filter \| filter()]]         | Создает новый массив из элементов, прошедших условие       |
| [[8. slice \| slice()]]            | Возвращает копию части массива                             |
| [[9. concat \| concat()]]          | Объединяет массивы и возвращает новый                      |
| [[10. flat \| flat()]]             | Создает новый массив, упрощая вложенные массивы            |
| [[11. flatMap \| flatMap()]]       | Выполняет `map()` и затем `flat(1)`                        |
| [[29. toSorted \| toSorted()]]     | Возвращает отсортированную копию массива                   |
| [[30. toReversed \| toReversed()]] | Возвращает копию массива с обратным порядком элементов     |
| [[32. toSpliced \| toSpliced()]]   | Возвращает копию массива с внесенными изменениями          |
| [[33. with \| with()]]             | Возвращает копию массива с замененным элементом по индексу |

Также есть методы, которые не изменяют исходный массив и возвращают не массив, а другое значение:

| Метод                            | Что возвращает                                      |
| -------------------------------- | --------------------------------------------------- |
| [[25. find \| find()]]           | Первый элемент, удовлетворяющий условию             |
| [[26. findIndex \| findIndex()]] | Индекс первого подходящего элемента                 |
| [[21. some \| some()]]           | `true`, если хотя бы один элемент подходит          |
| [[20. every \| every()]]         | `true`, если все элементы походят                   |
| [[18. reduce \| reduce()]]       | Результат последовательного накопления              |
| [[22. includes \| includes()]]   | `true` - если элемент найден или `false` - если нет |
| [[23. indexOf \| indexOf()]]     | Индекс первого найденного совпадения или `-1`       |
| [[35. join \| join()]]           | Строку из элементов массива                         |
| `forEach()`                      | `undefined`, выполняет функцию для каждого элемента |
### Пример
```js
const numbers = [1, 2, 3]

const doubled = numbers.map((num) => num * 2)

console.log(numbers) // [1, 2, 3]
console.log(doubled) // [2, 4, 6]
```
`map()` создал новый массив, оставив исходный без изменений.


## Важно

### `sort()` и `toSorted()`
```js
const numbers = [2, 5, 10]

numbers.sort((a, b) => a - b)

console.log(numbers) // [2, 5, 10]
```
```js
const numbers = [3, 1 ,2]

const sorted = numbers.toSorted()

console.log(numbers) // [3, 1, 2]
console.log(sorted) // [1, 2, 3]
```
`sort()` изменил исходный массив, а `toSorted()` вернул новый.

Важно: `sort()` по умолчанию сортирует элементы как строки.

### `splice()` и slice()
```js
const numbers = [1, 2, 3, 4];

numbers.splice(1, 2); // Удаляет элементы с индексами 1 и 2

console.log(numbers); // [1, 4]
```
```js
const numbers = [1, 2, 3, 4];

const part = numbers.slice(1, 3);

console.log(numbers); // [1, 2, 3, 4]
console.log(part);    // [2, 3]
```
`splice()` мутирует массив, `slice()` - нет.
