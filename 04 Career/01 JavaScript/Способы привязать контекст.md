# Способы привязать контекст: call, apply, bind

## Краткий ответ (30 секунд)

`fn.call(thisArg, a, b)` — вызывает функцию сразу с указанным `this` и аргументами **через запятую**. `fn.apply(thisArg, [a, b])` — то же самое, но аргументы **массивом**. `fn.bind(thisArg, a)` — **не вызывает**, а возвращает новую функцию, у которой `this` (и переданные «навсегда» аргументы) зафиксированы. Ещё способы: стрелочная функция (лексический `this`), `=>`-обёртка, `bind` в конструкторе/поле класса.

## Подробно

### Три метода

```js
function introduce(greeting, punctuation) {
  return `${greeting}, ${this.name}${punctuation}`;
}

const person = { name: "Аня" };

introduce.call(person, "Привет", "!");     // "Привет, Аня!"
introduce.apply(person, ["Привет", "!"]);  // "Привет, Аня!"
const bound = introduce.bind(person, "Привет", "!");
bound();                                    // "Привет, Аня!"
```

| Метод | Когда вызывает | Аргументы | Возвращает |
|---|---|---|---|
| `call` | сразу | по одному (`...args`) | результат вызова |
| `apply` | сразу | массив/`arrayLike` (`args`) | результат вызова |
| `bind` | позже | по одному (`...args`) | новую функцию |

- **Разница `call`/`apply`** — только в форме аргументов. `apply` удобен, когда аргументы уже лежат в массиве.
- **`bind`** создаёт *bound function*: у неё внутренние слоты `[[BoundThis]]` и `[[BoundArgs]]`. Повторный `bind` **не перезапишет** `this` первого `bind`, но аргументы будут накапливаться.
- `bind` можно использовать как частичное применение: `const double = add.bind(null, 2)`.

```js
function add(a, b) { return a + b; }
const inc = add.bind(null, 1); // this = null, a = 1 зафиксирован
inc(5); // 6

const incAgain = inc.bind({ ignored: true }, 10); // this остаётся null, второй thisArg не применяется
incAgain(5); // 16 — аргументы накапливаются
```

> [!warning] Тонкость
> `fn.bind(obj1).bind(obj2)` — `this` останется `obj1`, второй `bind` сам по себе `thisArg` не подменит. Аргументы первого и второго `bind` применяются по порядку: `add.bind(null, 1).bind(null, 10)(5) === 1 + 10 + 5 = 16`.

### Другие способы

- **Стрелочные функции** — лексический `this`, не переопределяется никаким `call`/`bind`. Основной способ в колбэках.
- **Обёртка**: `setTimeout(() => this.tick(), 1000)`.
- **`bind` в конструкторе**: `this.handleClick = this.handleClick.bind(this)` — классика React-классов.
- **Поле класса со стрелкой**: `handleClick = () => {}`.
- **`Reflect.apply`** — новее, безопаснее и работает при переопределённых `apply`; редко нужен на практике, но знание приятно.
- В React-функциях «привязки» контекста нет как таковой — `this` не используется.

### Как потерять контекст

```js
const obj = {
  value: 42,
  getValue() { return this.value; },
};

setTimeout(obj.getValue, 0); // setTimeout вызвал как fn() → undefined

setTimeout(obj.getValue.bind(obj), 0); // ок
```

То же самое с методами `Promise.prototype.then`: `promise.then(obj.getValue)` теряет `this`, а `promise.then(() => obj.getValue())` — сохраняет.

### Реализация `bind` руками (частый вопрос)

```js
function myBind(fn, ctx, ...boundArgs) {
  return function (...args) {
    return fn.apply(ctx, [...boundArgs, ...args]);
  };
}
```

Для `new` полноценная реализация учитывает `[[Construct]]`; на собеседовании обычно достаточно упомянуть это как ограничение.
