# Каррирование

## Краткий ответ (30 секунд)

**Каррирование** — преобразование функции от нескольких аргументов в цепочку функций по одному аргументу: `f(a, b, c)` → `f(a)(b)(c)`. Каждый вызов возвращает новую функцию, пока не собраны все аргументы. Оно тесно связано с **частичным применением** (фиксируем часть аргументов, остальные передаём позже) и используется для пресетов, композиции (`pipe`/`compose`), переиспользования обработчиков и в библиотеках вроде Ramda/lodash (`_.curry`).

## Подробно

### Ручная и универсальная реализация

```js
const add = (a) => (b) => (c) => a + b + c;

add(1)(2)(3); // 6
```

Общее решение — накапливать аргументы до `fn.length`:

```js
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) return fn.apply(this, args);
    return (...next) => curried.apply(this, [...args, ...next]);
  };
}

const multiply = curry((a, b, c) => a * b * c);
multiply(2)(3)(4);   // 24
multiply(2, 3)(4);   // 24
multiply(2, 3, 4);   // 24
```

**Важное ограничение:** `fn.length` не учитывает значения по умолчанию и rest-параметры:

```js
curry((a, b = 2) => a + b).length; // 1 — каррировать такую нельзя
curry((...args) => args.length).length; // 0
```

Для универсальности библиотеки используют placeholder (`_.partial`) или явное число аргументов (`curry(fn, 3)`).

### Зачем нужно

**1. Конфигурация и пресеты:**

```js
const request = curry((baseUrl, endpoint, options) =>
  fetch(baseUrl + endpoint, options),
);

const api = request("https://api.example.com");
const getUsers = api("/users");
const getUsersPage = getUsers({ page: 1 });
```

**2. Обработчики с аргументами в JSX:**

```js
const handleClick = curry((id, event) => select(id));
<button onClick={handleClick(item.id)}>…</button>
```

**3. Композиция (часто парой к каррированию):**

```js
const pipe = (...fns) => (x) => fns.reduce((v, f) => f(v), x);
const getAge = (user) => user.age;
const isAdult = (age) => age >= 18;

const isAdultUser = pipe(getAge, isAdult);
isAdultUser({ age: 20 }); // true
```

**4. Частичное применение на базе `bind`:**

```js
const power = (base, exp) => base ** exp;
const square = power.bind(null, 2); // фиксируем base = 2
square(5); // 25
```

### Каррирование vs частичное применение

- **Каррирование** — строго по одному аргументу: `f(a)(b)(c)`.
- **Частичное применение** — фиксация любого числа аргументов: `partial(f, 2)` → `f(2)(3)`.
- На практике «каррирование» часто означает «как в Ramda» — с возможностью передавать несколько аргументов сразу. Стоит уточнить на собеседовании.

### Минусы

- Каждый вызов создаёт новую функцию — аллокации.
- Сложнее читать, если увлекаться: `f(a)(b)(c)(d)(e)` в продакшене выглядит как головоломка.
- `this` нужно передавать явно (`curried.apply(this, ...)`), поэтому стрелки уместнее.
- Каррирование не дружит с функциями с необязательными параметрами (см. `fn.length`).
- Именованные/типизированные сигнатуры становятся сложнее в TS.

> [!tip] Как отвечать
> «Каррирование — `f(a,b,c)` → `f(a)(b)(c)`. Реализуется накоплением аргументов до `fn.length`. Близко к частичному применению; полезно для пресетов и композиции. Минусы — новые функции на каждом вызове и потеря читаемости при перегибе».
