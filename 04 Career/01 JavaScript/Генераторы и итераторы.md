# Генераторы и итераторы

## Краткий ответ (30 секунд)

**Генератор** — функция `function*`, которая возвращает **итератор** и умеет «ставить на паузу» на `yield`. Каждый `.next(value)` продолжает выполнение до следующего `yield` и возвращает `{ value, done }`. Через `.next(value)` можно передавать значения *внутрь* генератора. Генераторы используются для ленивых последовательностей, обхода данных, реализации async-лока (редко вручную), и внутри транспайлеров `async/await`. Сегодня чаще применяют итераторы и async-генераторы (стримы), чем генераторы в прикладном коде.

## Подробно

### Базовый генератор

```js
function* range(start, end) {
  for (let i = start; i < end; i++) yield i;
}

const it = range(0, 3);
it.next(); // { value: 0, done: false }
it.next(); // { value: 1, done: false }
it.next(); // { value: 2, done: false }
it.next(); // { value: undefined, done: true }

[...range(0, 3)]; // [0, 1, 2] — итератор совместим с for...of
```

### Передача значения внутрь

```js
function* dialog() {
  const name = yield "Как тебя зовут?";
  const age = yield `Привет, ${name}! Сколько тебе лет?`;
  return `Тебе ${age}.`;
}

const it = dialog();
it.next();          // { value: "Как тебя зовут?", done: false }
it.next("Аня");     // { value: "Как тебя зовут?" -> уже с Аня, done: false }
it.next(28);        // { value: "Тебе 28.", done: true }
```

Первый `next(arg)` игнорируется: генератор ещё не дошёл до `yield`. Это частый подвох.

### `return` и `throw`

```js
function* g() {
  try {
    yield 1;
    yield 2;
  } finally {
    console.log("cleanup");
  }
}

const it = g();
it.next();     // 1
it.return(99); // { value: 99, done: true }, сработает finally
```

`it.throw(new Error())` бросает ошибку *внутрь* генератора в точку `yield`.

### Зачем они нужны

1. **Ленивые последовательности** — бесконечные ряды (`function* naturals() { let i = 0; while (true) yield i++; }`), читаются с `.take`/`for...of` и `break`.
2. **Итерация по сложным структурам** — дерево, поток чанков.
3. **Библиотечные внутренности** — `redux-saga`, `effect-ts`, `co`, транспайлеры async/await.
4. **Управление ресурсами** — генератор с `try/finally`, `using` в спецификации повторяет идею.

### Async-генераторы

```js
async function* paginate(url) {
  let next = url;
  while (next) {
    const res = await fetch(next);
    const page = await res.json();
    yield page.items;
    next = page.next;
  }
}

for await (const items of paginate("/page/1")) {
  console.log(items);
}
```

Async-генераторы — удобный API для пагинации/стримов.

### Итератор (протокол)

```js
const iterator = {
  next() {
    return { value: 1, done: false };
  },
  [Symbol.iterator]() {
    return this;
  },
};

const iterable = {
  [Symbol.iterator]: function* () {
    yield 1;
  },
};
```

- **Итератор** — объект с методом `next()`.
- **Итерируемое** — объект с `[Symbol.iterator]()`, возвращающим итератор.
- Генератор — одновременно итератор и итерируемое.

### В чём подвох вопроса

Формулировка «где встречаются» — про `async/await` и `for...of`. Ответ: `for...of` работает через `Symbol.iterator`; массивы, `Map`, `Set`, строки итерируемы, а объекты — нет (у них нет `Symbol.iterator` по умолчанию).

> [!tip] Коротко
> «Генератор — пауза через `yield`, возвращает `{value, done}`. Итератор — протокол с `next()`. Async-генератор — то же, но с `await` и `for await`».
