# Рекурсия и её опасности

## Краткий ответ (30 секунд)

**Рекурсия** — приём, когда функция вызывает саму себя, пока не выполнится **базовый случай** (условие выхода). Опасности: 1) отсутствие/неверный базовый случай → бесконечная рекурсия → **переполнение стека** (`RangeError: Maximum call stack size exceeded`); 2) стек ограничен (в V8 — порядка 10⁴ вызовов, зависит от глубины), поэтому глубокие структуры/деревья могут упасть; 3) скорость и память — каждый вызов это кадр стека; 4) побочные эффекты и сложность отладки. Митигация — явный стек/очередь вместо рекурсии или tail-call в движках, где он есть.

## Подробно

### Базовая рекурсия

```js
function factorial(n) {
  if (n <= 1) return 1; // базовый случай обязателен
  return n * factorial(n - 1);
}
factorial(5); // 120
```

### Когда рекурсия — хороший выбор

- Обход дерева/вложенной структуры (DOM, JSON, меню).
- Разделяй и властвуй (quickSort, mergeSort).
- Задачи с естественной рекурсивной природой.

### Когда плохой

- Очень глубокая структура (глубина > нескольких тысяч).
- Простой цикл по массиву — `reduce`/`for` читаются лучше и быстрее.
- Ханойская башня или `fib` без мемоизации — экспоненциальная сложность.

```js
// Плохо: O(2^n)
function fib(n) {
  return n < 2 ? n : fib(n - 1) + fib(n - 2);
}

// Хорошо: мемоизация или итерация
function fibIter(n) {
  let [a, b] = [0, 1];
  for (let i = 0; i < n; i++) [a, b] = [b, a + b];
  return a;
}
```

### Переполнение стека

```js
function sum(n) {
  return n === 0 ? 0 : n + sum(n - 1);
}
sum(100_000); // RangeError
```

В V8 размер стека фиксирован (по умолчанию ~1 МБ на поток), и кадр каждого вызова — это память; глубина ограничена (обычно порядка 10 000 кадров, но зависит от размера кадра). На собеседовании полезно напомнить, что «хвостовая рекурсия» **в V8 не оптимизируется** (нет TCO), поэтому `sum` в хвостовой форме всё равно упадёт.

### Чем заменить

**1. Явный стек/итерация:**

```js
function flatten(node) {
  const stack = [node];
  const result = [];
  while (stack.length) {
    const cur = stack.pop();
    result.push(cur.value);
    if (cur.children) stack.push(...cur.children);
  }
  return result;
}
```

**2. Аккумулятор для сумм/свертки:**

```js
function sum(arr) {
  let total = 0;
  for (const x of arr) total += x;
  return total;
}
```

**3. `reduce` для свертывания** — тот же принцип, но без рекурсии.

**4. Мемоизация/`Map` для повторяющихся подзадач** — `fibbonacci`, задачи на пути в графе.

### Про мемоизацию

Кэш превращает экспоненциальную рекурсию в линейную, но добавляет память. `Map` из `[[Каррирование]]` или `useMemo` — примеры на практике.

### Что сказать на собеседовании

> «Рекурсия естественна для деревьев, но каждый вызов — кадр стека, и при глубокой структуре мы поймаем `RangeError`. V8 не делает tail-call оптимизацию, поэтому хвостовая рекурсия не спасёт. Для продакшена предпочитаю явный стек или итерацию».
