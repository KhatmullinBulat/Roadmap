На телефоне лежит своя история: коммит `56f1ccf` (тот самый старый бэкап) и, скорее всего, ещё локальный коммит после него. Он не совпадает с переписанной `main`. **Через обычное расширение Git для Obsidian — да, можно.** Причём консоль не нужна, если действовать по шагам ниже.

Свежая версия плагина умеет решать конфликты прямо в Obsidian: команда `Open source control view` → секция **Conflicts** → тап по файлу → блоки подсвечены, для каждого кнопки **Keep ours** / **Keep theirs** / **Keep both** → рядом с файлом иконка **Mark resolved** → когда Conflicts пусто, ввести сообщение и нажать **Commit**, затем снова Commit-and-sync.

Но для твоего случая есть путь проще и безопаснее, чем разбирать 100+ конфликтов вручную.
